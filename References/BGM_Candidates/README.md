## 사용 조건

Kevin MacLeod 4곡은 크레딧 표기가 필요한 무료 CC BY 4.0이다. 게임 크레딧에 아래 LICENSES.md의 해당 곡 표기와 라이선스 링크를 넣고 편집했다면 변경 사실도 적는다.
CC0 2곡은 저작자 표시 의무 없이 상업적 사용·편집이 가능한 배포다. 출처 기록은 함께 보관한다.
[제작자 무료 라이선스 안내](https://incompetech.com/music/royalty-free/licenses/) · [크레딧 및 개별 출처](LICENSES.md)

원본 파일 외에 프리뷰·변환 WAV·중복 백업은 만들지 않았다. Bleak Terminal은 게임에 필요한 사본을 Resources에 두었다. manifest.json에는 최초 6곡의 원본 링크·용량·SHA-256을 기록했다.

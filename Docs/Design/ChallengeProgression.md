# 5단계 도전과 확장 아이템

## 구현한 도전 흐름

1. 단골 손님 → 2. 배달원 → 3. 주방장 → 4. 지배인 → 5. 사장.
1~4단계 승리 후 기존 승리 화면의 다음 보스 버튼/Enter로 진행한다. 5단계 승리는 별도 Completed 상태와 도전 완료 화면으로 종료한다. 6단계로 넘어가지 않으며 새 도전은 1단계부터 시작한다.

모든 단계가 기존 보스 모델과 외형을 공통으로 사용한다. 단계별 모자·앞치마·조끼·코트 및 셔츠 색 변경 기능은 후속 요청으로 삭제했다. 단계 이름과 아이템 풀, 체력 진행은 유지한다.

| 단계 | 보스 | 외형 | 일반 아이템 풀 |
|---|---|---|---:|
| 1 | 단골 손님 | 기존 보스 공통 외형 | 7종 |
| 2 | 배달원 | 기존 보스 공통 외형 | 11종 |
| 3 | 주방장 | 기존 보스 공통 외형 | 15종 |
| 4 | 지배인 | 기존 보스 공통 외형 | 18종 |
| 5 | 사장 | 기존 보스 공통 외형 | 19종 |

의상 생성 및 맞춤 메시 계산은 제거했다. 원본 리그의 뼈 위치와 애니메이션은 유지한다.

플레이어 최대 체력은 5, 보스 최대 체력은 단계별로 **3 / 4 / 5 / 5 / 5**다. 기존처럼 다음 보스에서 플레이어 체력은 최대치로 회복하고, 플레이어 잔여 아이템/토큰은 유지한다. 보스 시작 토큰은 단계별 **0 / 2 / 3 / 4 / 6**, 시작 아이템은 해당 단계 풀에서 무작위 **2 / 2 / 3 / 3 / 4개**로 초기화한다. AI의 기존 단계별 판단 정밀도 상승을 유지하며, 단계가 올라갈수록 강한 공격/교환 아이템이 추가된다. 폭발 결과 RNG를 읽거나 보스에게 유리하게 조작하지 않는다.

## 새 아이템 5종

| 아이템 | 효과 | 최초 등장 | 참고 가격 |
|---|---|---:|---:|
| 소금 봉지 | 상대의 다음 흔들기 압력 +2. 중복 가능 | 2 | 3 |
| 보냉팩 | 내 다음 흔들기 압력 -2 | 2 | 4 |
| 계산 펀치 | 상대 다음 흔들기 토큰 -3 | 3 | 4 |
| 새 뚜껑 | 이 콜라의 한계 압력 +3 | 4 | 4 |
| 교환권 | 자신을 다른 무작위 아이템으로 교체 | 5 | 4 |

가격은 카탈로그 참고값이다. 일반 획득은 기존 웨이터벨 6토큰/2개 무작위 배달이며, E는 전체 19종을 무료로 받는 테스트 메뉴다. 개별 가격으로 구매하는 상점을 추가하지 않았다.

강도별 기본 압력 증가는 +2/+4/+8이다. 발포 캔디는 상대의 다음 흔들기에 +4, 소금은 +2의 추가 압력을 예약하며 중첩한다. 사용자의 현재 압력을 직접 높이지 않는다. 대상이 흔들 때 콜라에 실제 반영되고 소비되며, 이후 실제 상승한 압력은 콜라에 남는다. 차례 넘기기와 새 콜라에서는 예약 효과를 유지하고 새 보스/재시작에서 초기화한다.

보냉팩은 내 다음 흔들기의 압력 증가를 2 줄이고 소비되며 중첩하지 않는다. 압력 공격이 없다면 강도별 증가는 +0/+2/+6이다. 현재 압력을 내리지는 않으며, 압력이 오르지 않아도 현재 압력 기준으로 폭발을 판정한다. 안전 마개는 내 다음 흔들기 확률 -15%p/개, 매운맛 주문서는 상대의 다음 흔들기 확률 +15%p/장으로 각각 중첩한다. 플레이어와 보스 모두 같은 중첩 규칙을 쓰며, 모든 대기 효과는 적용 대상이 실제로 흔들 때 한꺼번에 소비한다. 최종 확률은 0~100%이고 한계 도달과 W 강제 폭발은 100%를 유지한다. 탄산 시럽은 삭제했다.

교환권은 자신을 다른 무작위 아이템 하나로 바꾼다. 교환권으로 다시 바뀌지 않으며 교체품은 현재 단계의 풀을 따른다. 다른 보유 아이템은 필요 없다. 보스 AI도 다섯 아이템의 효과와 가치를 평가해 사용한다.

각각 새로운 OBJ 모델, 공유 컬러 재질, 사용 제스처와 고유 SFX를 연결했다. 모델은 기존 슬롯 크기에 맞췄으며 새 이미지 생성/프리뷰는 사용하지 않았다.

- 단계가 오르면 기존 풀을 유지하며 새 종류가 해금되고 상대적 비중이 달라진다. 기존에 보유한 아이템은 회수하지 않는다.

- 실제 게임 코드는 `ColaItemCatalog.DropWeightFor(id, level)`를 사용한다. 기존 `ColaItemDefinition.DropWeight`는 과거 도구 호환용이며 현재 단계별 확률이 아니다.
- 현재 가중치는 유지했다. 가상 대전의 가정과 통계는 `output/verification/latest/campaign-balance/Report.md`에 보관하며, 오프라인 모델 결과를 Unity Play 검증으로 간주하지 않는다.

## 공용 능력 17종 — 구현

플레이어와 보스의 폭발을 합산해 3/6/9…회마다 미보유 능력 중 무작위 후보 3개를 제시하고 1개를 선택한다. 폭발 후 검은 화면과 페이드인이 끝난 다음 실제 메뉴판 모델의 선택 화면이 뜨며, 선택하는 동안 다음 턴은 진행하지 않는다. 미보유 능력이 2개 또는 1개만 남으면 그만큼만 제시한다. 17종을 전부 얻었으면 더 이상 선택을 띄우지 않는다. 후보 RNG는 폭발/아이템/AI RNG와 분리했다.

사망 또는 최종 도전 완료 시에는 선택을 띄우지 않는다. 1~4단계 보스 격파와 획득 시점이 겹치면 능력을 먼저 고르고 다음 보스로 진행한다. 능력과 폭발 카운터는 보스를 넘어 유지하며 새 도전에서 초기화한다. **TAB**으로 메뉴판 모델의 기록부를 열고, 내 능력/상대 능력/업적 탭에서 기록을 확인한다.

| 능력 | 간단한 효과 |
|---|---|
| 단골 할인 | 웨이터벨 가격 -1토큰 |
| 가벼운 손 | 강도 1로 생존하면 토큰 +1 |
| 과감한 선택 | 강도 3으로 생존하면 토큰 +2 |
| 파손 보상 | 내 차례에 폭발하면 토큰 +2 |
| 첫 주문 서비스 | 획득 후 다음 벨부터, 보스마다 배달 1회 +1개. 추가 빈 칸이 없으면 일반 주문 후 보너스 유지 |
| 정리 쿠폰 | 획득할 때와 새 보스 시작 시 교환권 1개. 가득 차면 빈 칸을 기다려 지급 |
| 알맞은 힘 | 강도 2로 생존하면 토큰 +1 |
| 침착한 손 | 체력 2 이하일 때 폭발 확률 -5%p. 한계 도달 시 100% |
| 여유 자금 | 흔들기 확정 시 12토큰 이상 보유하고 생존하면 토큰 +1 |
| 재활용 적립 | 획득 후 아이템을 3개 사용할 때마다 토큰 +1 |
| 넉넉한 수납 | 트레이 +2칸 |
| 위험 수당 | 예상 폭발 확률 50% 이상에서 생존하면 토큰 +1 |
| 정기 납품 | 새 콜라마다 무작위 아이템 1개. 가득 차면 빈 칸을 기다림 |
| 거친 손맛 | 강도 3으로 생존하면 상대의 다음 흔들기 압력 +2 |
| 위기 대처 | 체력 2 이하에서 폭발 확률 -10%p. 한계 도달 시 100% |
| 선불 계약 | 각 콜라의 첫 벨 주문 가격 -2토큰 |
| 사고 수당 | 내 차례에 폭발하면 토큰 +4 |

능력 17종은 플레이어와 보스 모두 같은 효과로 적용한다. 플레이어는 선택으로 획득하고 보스는 아래 단계별 고정 능력으로 시작한다. 아이템 의존 능력 3종을 위 능력으로 교체하며 저장된 ID는 유지한다. 침착한 손은 예측과 실제 판정에 동일하게 반영한다. 여유 자금은 흔들기 확정 시 보너스를 기록하므로 연출 중 주문으로 토큰이 줄어도 해당 보너스를 잃지 않는다. 토큰 보정은 실제 지급과 콜라 설명에 함께 반영한다. 첫 주문 서비스는 획득 시 1회분을 준비하고 새 보스마다 갱신한다. 빈 칸이 3개 이상이면 다음 벨 배달에 +1하고 해당 보스의 보너스를 소비한다. 빈 칸이 2개뿐이면 일반 2개 주문은 허용하고 보너스를 유지한다. 정리 쿠폰은 획득 시 및 새 보스 시작 시 1개를 예약하며, 트레이가 가득 차면 행동/메뉴가 끝난 뒤 빈 칸이 생길 때 지급한다. R은 예약된 지급도 비운다. 재활용 적립은 능력을 고른 후의 사용 횟수만 센다. 수납은 내 물리 트레이를 4열×2행에서 5열×2행으로 다시 만들며, 트레이의 전체 폭을 유지하고 아이템 크기를 맞춘다. 보스도 넉넉한 수납을 가지면 같은 방식으로 10칸 트레이를 사용한다.

| 교환 단골 (신규) | 한 도전에서 교환권 3회 사용 |
| 능력 수집 (신규) | 한 도전에서 능력 4개 획득 |

업적 달성 여부와 누적 사용 아이템 종류는 `PlayerPrefs`의 전용 키 `COLA_COLA.Achievements.v1`에 JSON으로 저장한다. 도전 재시작 및 Play 종료 후에도 업적은 유지한다. **TAB**으로 기록부를 열어 26종의 조건과 달성 여부를 볼 수 있다. 항목의 설명/조건은 메뉴판 모델 하단에 표시한다. 달성 시 작은 문구로 알려주며 Steam 업적 연동은 포함하지 않는다.

Q/W/E/R/T/Y/V 또는 단계 변경 버튼을 사용한 순간부터 해당 도전은 업적 및 누적 아이템 사용 기록에서 제외한다. 디버그를 끄거나 다른 보스로 넘어가도 제외 상태가 유지되며, 새 도전을 시작하면 해제한다. 새 도전은 W/E도 꺼진 상태로 시작한다. 디버그 사용 전에 정상 플레이로 이미 달성·저장한 업적은 유지한다. 능력 선택과 적용은 디버그 도전에서도 가능하다.

한 보스 동안의 폭발·벨·아이템·강도 기록은 보스마다 초기화한다. 벨 5회, 교환권 3회, 연속 생존 및 능력 4개는 도전 전체 기록이다. 강도 1/3 단독 업적은 실제 흔들기를 적어도 한 번 해야 한다. 교환권으로 바뀐 아이템의 출처를 슬롯별로 추적하고 집게로 바뀌어도 따라가며, 소모/삭제/재지급 시 출처를 초기화한다.

## 디버그 조작

- 좌측 상단 **1·2·3·4·5 버튼**: 해당 단계로 바로 이동. 체력·현재 콜라·양쪽 인벤토리와 보스 지갑을 새 단계 기준으로 초기화하고 플레이어 능력과 지갑은 유지한다. 진행 중 모션을 취소하고 시작한다. 보통 압력 선택 키 1/2/3은 유지한다.
- **Q**: 실제 플레이어 토큰 999.
- **W**: 양쪽 폭발 확률 100% 전환.
- **E**: 무료 테스트 메뉴. 단계 제한 없이 전체 19종을 오른쪽 스크롤바/마우스 휠로 탐색한다. 품목별 수량 슬라이더로 0~남은 빈 칸만큼 담아 ‘무료 받기’로 한 번에 지급한다. 같은 아이템도 여러 개 가능하다.
- **T**: 메뉴판 모델의 업적 디버그창. 항목 클릭으로 개별 달성/해제, 하단 버튼으로 전체 달성. 이 창의 명시적 디버그 변경은 로컬 저장에 반영한다.
- **Y**: 메뉴판 모델의 능력 디버그창. 전체 12종 중 원하는 능력 또는 전체 능력을 획득한다. 능력은 이번 도전에서만 유지한다.
- **V / 좌측 상단 승리 버튼**: 현재 단계 테스트 승리. 진행 중 모션과 메뉴/능력 선택을 정리하고 보스 HP를 0으로 바꿔 실제 종료 UI로 전환한다. 1~4단계는 다음 보스, 5단계는 도전 완료/새 도전이다. 테스트 승리 자체는 업적이나 흔들기 보상을 지급하지 않는다.
- **TAB**: 보유 능력/업적 기록부를 열고 닫는다. 능력/업적 탭으로 전환하고, 스크롤로 목록을 탐색한다.
- **R**: 양쪽 보유 아이템과 테스트 메뉴 장바구니를 전부 비운다. 진행 중 아이템/배달 연출을 정리하며 이미 사용한 효과·체력·토큰·능력은 유지한다. 재시작은 종료 화면의 새 도전/Enter를 이용한다.
- 디버그 키와 단계 버튼은 공용 `ColaDuelController.ApplyDebugCommand`를 호출하며 Editor/Development Build에서만 제공한다.

## 효과 압력 예측과 강도 3 능력 — 개정 5

- 선택한 강도의 기본 예상 압력은 기존 주황 점선으로 표시한다. 받은 추가 압력은 붉은 점선, 보냉팩 감소를 반영한 최종 압력은 청록 점선으로 따로 표시한다. 추가와 감소가 동시에 있으면 기본/추가 후/감소 후의 세 위치를 구분한다.
- 점선은 같은 전환 시간으로 부드럽게 이동하며, 확률 숫자는 모든 효과를 적용한 최종 압력 기준이다. 효과가 없거나 흔들기를 확정하거나 새 콜라로 초기화하면 해당 효과 점선을 숨긴다. 확률만 바꾸는 안전 마개/침착한 손은 압력 점선 위치를 바꾸지 않는다.
- 추가 점선은 기존 점선 모델을 Play에서만 재사용해 생성한다. 저장된 씬·프리팹을 재생성하지 않으며 종료 시 전용 오브젝트와 재질을 해제한다.
- 과감한 선택의 강도 3 생존 보너스는 +1에서 +2토큰으로 변경한다. 기본 생존 보상 4토큰은 유지하므로 해당 능력만 있으면 강도 3 생존 시 6토큰이다. 폭발 보상에는 적용하지 않는다. 가상 대전 도구의 보상과 집계도 같은 상수를 읽도록 맞춘다.
- 이번 변경에는 Play·컴파일 검사·가상 대전·캡처를 실행하지 않았다. 기존 개정 4 분석 보고서는 이번 보너스 변경의 분석 결과가 아니다.

## 최종 압력 강조와 보스 대기 동작 — 이전 표시 사양

- 최종 예상 압력에 밝은 상아색 점선 화살표를 추가한다. 기본 화살표보다 7.5% 길고 횡폭 배율 1.65로 강조하며 눈금 안쪽에 끝나도록 한다. 기본/추가/감소 위치는 기존 보조 점선으로 유지한다. 효과가 없을 때는 최종 점선만 표시한다. 최종 화살표는 실제 최종 확률과 같은 예상 압력을 향해 기존 전환 시간으로 움직인다.
- 기존 6가지 대기 동작에 압력계 살피기, 보유 아이템 살피기, 작은 한숨과 자세 정돈, 차례로 손가락 두드리기, 생각하다 콜라로 시선 돌리기, 높은 공개 압력에서의 긴장 자세 6종을 추가한다. 직전 동작은 반복하지 않는다. 본인 차례와 공개 압력에 따라 생각/긴장 동작의 선택 비중이 달라진다. 연출 전용 난수를 사용해 게임 결과에 영향을 주지 않는다.
- 몸통을 움직이는 동작은 원본 리그의 팔 길이를 유지하는 회전 보정으로 기존 양손 위치와 방향을 유지하도록 한다. 손과 팔의 본 위치·스케일은 직접 바꾸지 않는다. 매 프레임 이전 가산 포즈를 복원하며 흔들기·아이템 사용·배달·폭발 중에는 가산 동작을 멈춘다. 사용 중인 원본 Idle과 흔들기 클립은 교체하지 않는다.
- 이번 표시/모션 변경은 Play·컴파일 검사·가상 대전·게임 캡처로 확인하지 않았다. 기존 개정 4 통계는 이 변경의 검증 결과가 아니다.

## 공용 능력과 단계별 보스 능력 — 개정 7 (현재)

안전 점검 능력은 추가하지 않고 위 5종을 추가했다. 기존 안전 마개 사용 업적의 이름은 유지한다. 전체 17종의 보상·할인·확률·수납·지급 효과를 양쪽 공통 경로로 계산한다. 플레이어의 선택 후보는 전체 17종이며 보스 능력은 단계별로 초기화한다. TAB의 상대 능력 탭에서 고정 조합과 효과를 확인할 수 있다.

| 단계 | 보스 시작 능력 수 | 능력 |
|---|---:|---|
| 1 | 0 | 없음 |
| 2 | 1 | 가벼운 손 |
| 3 | 2 | 가벼운 손, 단골 할인 |
| 4 | 4 | 가벼운 손, 단골 할인, 거친 손맛, 정기 납품 |
| 5 | 6 | 가벼운 손, 단골 할인, 거친 손맛, 정기 납품, 위기 대처, 선불 계약 |

- 정기 납품은 새 콜라가 시작할 때마다 1개를 예약한다. 단계 첫 콜라에도 적용하며 슬롯이 가득 차면 빈 칸을 기다린다. R로 예약까지 삭제한다. 획득한 현재 콜라에는 소급 지급하지 않는다.
- 거친 손맛은 생존한 강도 3 뒤 상대의 다음 실제 흔들기에 +2를 예약한다. 중복된 상대 예약 압력과 합산하며 넘기기나 새 콜라로 사라지지 않는다.
- 위기 대처는 낮은 체력에서 -10%p이고 침착한 손과 합쳐 -15%p다. 안전 마개와도 더해지며 한계 도달은 계속 100%다.
- 선불 계약은 콜라별로 양쪽의 첫 벨 주문을 따로 기록한다. 단골 할인까지 있으면 첫 주문 3토큰, 그 뒤 5토큰이다. 주문 뒤에 능력을 얻어도 그 콜라의 첫 주문을 소급 초기화하지 않는다.
- 사고 수당은 폭발 기본 5토큰에 +4다. 파손 보상까지 있으면 11토큰을 받는다.
- 보스의 자체 보상·실제 할인된 벨 가격과 거친 손맛의 다음 상대 위험을 AI 효용 평가에 반영한다. 숨은 결과 RNG는 읽지 않는다. 첫 주문 서비스/정리 쿠폰/재활용 적립/수납도 보스가 보유하면 동작한다.

8개 능력 수 구성을 각 2,000회 비교하고 **0/1/2/4/6개**를 채택했다. 후보 선택에 쓰지 않은 별도 시드 10,000회에서 완주 1,691회(16.91%), 단계 도달률은 100/85.12/69.24/48.31/30.73%였다. 도달 후 격파율은 85.12/81.34/69.77/63.61/55.03%로 후반까지 내려갔다. 같은 새 능력 풀에서 보스 능력이 없으면 완주율은 35.57%였다. 비축 정책은 21.32%, 경제 능력 우선 정책은 30.28%였다. 사람의 실제 승률이 아니라 정책 가정에 따른 오프라인 추정이다.

이전 개정 6의 10,000회 완주/도달 횟수를 재현했다. 현재 추천은 고정된 능력 우선순위와 명시된 정책에 대한 결과이며, 능력 조합이 달라지면 같은 개수도 강도가 달라진다. 최신 통계·95% 구간·평균 시간·후보별 비교는 `output/verification/latest/campaign-balance/Report.md`에 모았다. Unity Play·컴파일 검사·Game 뷰 검증·캡처는 실행하지 않았다.

## 사용 가능성·반납·메뉴·번역 — 개정 8 (현재)

- 취소 번호표: 토큰 +1, 상대 아이템 1개 제거. 상대가 비어 있어도 사용 가능.
- 교환 집게: 상대 무작위 아이템 1개 획득, 없으면 현재 단계의 무작위 아이템 획득.
- 빨대: 항상 2토큰 획득. 상대 토큰이 있으면 최대 2개까지 가져오고 부족분은 생성.
- 계산 펀치: 상대 다음 실제 흔들기 최종 토큰 보상 -3. 중복 가능, 최저 0. 넘기기/새 콜라에도 유지.
- 교환권: 자신을 교환권이 아닌 무작위 아이템으로 교체. 다른 아이템이 필요 없다.
- 자기 턴에 자기 아이템을 우클릭 0.55초 누르면 1토큰으로 반납한다. 사용/배달 중에는 불가하며 한 번 누르기에 한 개만 반납한다. 재활용 적립과 사용 업적에는 포함하지 않는다. 보스도 공간 때문에 주문이 막히면 가치가 낮은 아이템을 같은 가격으로 반납할 수 있다.
- 취소/탈취/교환 아이템의 강화된 효율을 고려해 등장 비중을 낮췄다. 위 확률 표가 현재 적용 수치다. 핫소스 병당 제한과 단계별 풀·체력·능력 수는 유지한다.
- 사용한 교환권/집게 모델을 분리한 후 새 아이템을 지급해 새 모델이 사용 연출로 사라지는 문제를 예방한다.
- 잔고 정리 업적은 계산 펀치로 상대 흔들기 보상을 0으로 만드는 조건이다.

### 메인 메뉴와 설정

Play/실행 시작 시 피자리아 배경 위에 COLA_COLA 메인 메뉴가 열린다. 게임 시작, 설정, 게임 종료를 배치하고 우측 하단에 크레딧을 둔다. 크레딧은 현재 음악 Bleak Terminal/Ruskerdax와 Simple PSX Character/JashiPSX를 포함한다.

ESC로 설정을 열고 다시 ESC 또는 닫기로 원래 화면에 돌아간다. ESC 안내 텍스트는 추가하지 않는다. 설정은 메인 볼륨, 해상도, 전체화면 ON/OFF, 메인 메뉴 이동이다. 볼륨/화면 설정은 PlayerPrefs에 저장한다. 종료는 빌드에서 앱 종료, Unity Editor에서는 Play 종료다.

설정은 게임 시간·실시간 연출 시계·대기 코루틴·물리/애니메이터·폭발 파티클·게임 음향을 정지시킨다. BGM은 계속 재생한다. 입력·벨·아이템·디버그 단축키와 배경 HUD는 메뉴가 열렸을 때 막는다. 메인 메뉴 이동 후 게임 시작은 새 도전이다.

### 번역 파일

`Assets/Localization/COLA_COLA_Translations.xlsx`의 첫 시트에서 Key/Context/언어별 칸을 관리한다. 현재 169개 키와 ko/en/ja/zh-Hans/zh-Hant/fr/de/es/pt-BR/ru 열이 있다. 한국어 원문과 영어 초안을 채웠고 다른 언어는 입력용으로 비워 뒀다. 빈 번역은 한국어로 표시한다. `{0}` 같은 매개변수 표시는 유지한다.

저장하면 Editor의 XLSX 가져오기가 `Resources/Localization/Strings.json`을 갱신한다. 기본 언어는 ko이며 `ColaLocalization.SetLanguage(code)`로 바꾼다. Unity 메뉴 COLA_COLA/Localization/Language에서도 한국어/영어/일본어를 고를 수 있다. 아이템·능력·업적과 메뉴·설정·핵심 안내문을 연결했다. 모델에 새긴 글자와 개발 로그는 번역 대상에서 제외한다.

### 분석과 확인 범위

세 확률 구성을 각 3,000회 탐색하고, 채택한 구성을 별도 시드로 10,000회 분석했다. 완주율은 18.15%, 단계별 도달률은 100.00/86.42/71.51/49.58/31.64%다. 실제 수치는 최신 Report.md/results.json을 우선한다. 판단 4초 등을 가정한 단계별 평균 시간은 약 4.4~5.4분이다. 아이템을 적극 사용하는 모델이라 사람이 아이템을 아끼며 겪는 슬롯 부족과 반납 효과를 충분히 재현하지 못한다.

이번에는 사용자가 요청한 오프라인 가상 대전과 컴파일 검사만 진행한다. Unity Play 진입·메뉴/애니메이션 동작 검사·Game 뷰 확인·게임 화면 캡처는 하지 않는다.

## 설정 디자인과 메인 메뉴 배경 — 후속 변경

- 메인 볼륨은 녹색 레벨 바, 눈금, 아이보리 손잡이와 백분율로 표시한다. 클릭/드래그와 초점 상태의 좌우 방향키/Home/End를 지원한다.
- 해상도는 1280×720, 1366×768, 1600×900, 1920×1080, 2560×1080, 2560×1440, 3440×1440, 3840×2160의 고정 후보 중 현재 모니터 크기 이내만 표시한다. 주사율별 전체 모드 목록은 사용하지 않는다. 저장된 값이 후보에 없으면 가까운 프리셋으로 맞춘다.
- 언어 드롭다운은 번역 XLSX의 언어 코드를 읽고 원어 이름으로 표시한다. 번역이 전부 비어 있는 언어는 선택하지 못하며, 비어 있는 개별 문구는 기존처럼 한국어로 표시한다. 현재 한국어와 영어 초안이 선택 가능하다. 선택값은 저장한다. ESC는 열린 언어 목록부터 닫고 그 다음 설정을 닫는다.
- XLSX에는 ui.language 키를 추가했다(총 170개). 기존 번역과 언어 열을 유지하고 사용법의 언어 변경 안내를 갱신했다.
- 메인 메뉴에서는 배경 직원의 첫 등장 대기를 2.5초로 줄이고 주기적으로 왕복하게 한다. 실제 대전 시간과 분리한 배경 시계만 진행한다. 게임 중 설정에서는 직원도 계속 정지한다. 메뉴에서 발소리를 쌓아 두지 않는다.
- 작은 부유 입자와 간판의 느린 밝기 변화를 추가한다. 입자는 메뉴용 실시간 시계로만 재생하며, 게임 시작 시 제거한다. 조명이나 게임 카메라를 움직이지 않는다. 입자 재질/오브젝트는 런타임 생성 후 종료 시 해제한다.
- 이 후속 변경에는 Unity Play·컴파일 검사·가상 대전·Game 뷰 확인을 실행하지 않았다. 이전 컴파일/통계는 이 변경의 검증 결과가 아니다.

# 플레이 가능한 기본 대전

`Assets/Scenes/MainScene.unity`에서 Play를 누르면 보스와 1대1 경기가 시작된다. 자동 손 미리보기는 껐고, 테스트 아이템·쟁반과 아이템용 보조광은 숨겼다. 에셋은 추후 사용을 위해 유지한다.

## 조작

- 테이블의 1·2·3 버튼 또는 숫자키로 흔들기 강도를 선택한다.
- 중앙 콜라 클릭 또는 Space로 확정한다. 선택 전에는 확정되지 않는다.
- 자신의 손 동작 이후 보스가 자동으로 행동하며, 보스가 끝나면 다시 선택한다.
- R은 경기 도중에도 전체 진행을 초기화한다.
- 승리 시 NEXT LEVEL 버튼 또는 Enter로 다음 난이도에 도전한다. 패배 시 RESTART RUN 또는 Enter로 처음부터 재시작한다.

## 임시 경기 규칙

- 플레이어와 첫 보스의 체력은 각각 3이다. 자기 차례에 폭발 판정이 나면 해당 인물의 체력이 1 감소한다.
- 체력이 0이면 즉시 승패를 확정하고 추가 행동을 막는다. 플레이어가 패배한 뒤 보스가 추가로 흔들지 않는다.
- 보스를 격파할 때마다 같은 보스의 최대 체력이 1 증가한다. 최대 99이며, 다음 대전 시작 시 플레이어 체력은 전부 회복한다.
- 안전한 행동은 강도만큼 1·2·3토큰, 폭발한 행동은 강도와 관계없이 **총 5토큰**을 받는다. 양쪽 단말기에 체력과 토큰을 실제 상태로 표시한다.
- 플레이어 토큰은 다음 난이도에 이어지고, 새 보스의 토큰은 0부터다. 전체 재시작은 난이도 1·토큰 0으로 초기화한다. 현재는 표시 범위에 맞춰 9,999토큰이 상한이며 사용처는 없다.
- 새 병의 공개 한계는 **20~30**이다. 폭발 확률은 `min(1, 흔든 뒤 압력 / 한계)`의 **1.5제곱**이며 한계 도달 시 100%다. 초반 확률을 높이기 위해 이전 지수 2에서 낮췄다. 한계 25·현재 압력 5에서는 강도 1/2/3이 11.8%/14.8%/18.1%다. 보스는 임시로 강도 1~3을 무작위 선택한다.
- 아이템 효과·상점은 제외했다. 폭발은 원본 손으로 병을 잡고 흔드는 도중 약 0.24초의 압력 고조 뒤 발생한다. 뚜껑·탄산·거품·손 반동·카메라 충격·파열음이 재생되고 손 동작이 끝난 뒤 새 병으로 교체한다. 피해와 토큰은 기존 결과 콜백에서 한 번만 적용한다. 연출 상세는 `Docs/Art/ColaBurst.md`를 따른다.

## 연결과 검증

`08_Devices/DuelRules`의 `ColaDuelController`가 경기 상태와 보상을 관리한다. 기존 `ShakeSelectionInteraction`은 압력·교대 행동, `StatusTerminalDisplay`는 실제 3D 단말기 표시를 담당한다. `ColaDuelHUD`는 차례·결과·조작 안내·다음 경기 버튼만 표시한다.

`COLA_COLA > Set Up Playable Duel`은 현재 씬에 해당 연결을 적용한다. 검증은 `PlayableDuelVerification.Begin`으로 Play 모드에서 진행한다. 실제 Raycast 입력, 원본 손 동작의 상태, 보상·피해·사망 후 입력 잠금, 다음 난이도, 중단·재시작 및 두 번째 Play 진입을 검사한다. 결과는 `output/playable-duel/Playmode-validation.txt`와 Unity 로그를 따른다. 별도 카메라나 프리뷰 캡처를 만들지 않으며 자동 검사 통과를 실제 Game 뷰 시각 확인으로 표현하지 않는다.

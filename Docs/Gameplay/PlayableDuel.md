# 플레이 가능한 기본 대전

`Assets/Scenes/MainScene.unity`에서 Play를 누르면 보스와 1대1 경기가 시작된다. 자동 손 미리보기는 껐고, 테스트 아이템·쟁반과 아이템용 보조광은 숨겼다. 에셋은 추후 사용을 위해 유지한다.

## 조작

- 테이블의 1·2·3 버튼 또는 숫자키로 흔들기 강도를 선택한다.
- 중앙 콜라 클릭 또는 Space로 확정한다. 선택 전에는 확정되지 않는다.
- 다음 조작을 알리는 호버 아웃라인: 마우스를 올린 1·2·3 버튼의 `BeveledKeycap` 본체를 표시하며, 강도 선택 후 다른 버튼으로 변경할 때도 같은 호버를 유지한다. 강도 선택 후에는 콜라에 마우스를 올릴 때 몸통·뚜껑·라벨을 합친 바깥 윤곽을 표시한다. 마우스를 떼면 즉시 숨긴다. 클릭과 같은 첫 충돌 Raycast를 사용해 다른 소품이나 주문서 뒤의 대상은 강조하지 않는다. 3D 숫자는 제외 마스크만 사용하고 색 선은 그리지 않으며, 라벨 글자와 내부 경계도 표시하지 않는다. SkinnedMeshRenderer와 블렌드 셰이프를 지원한다. 강도 3 강제 효과 중에는 3번만 안내한다. 주문서 집기/내려놓기 중, 흔들기·폭발·페이드·보스 턴·승패 확정 시에는 숨긴다. 명도를 조금 낮춘 황금색이며 버튼과 콜라 모두 2.5픽셀이다. `ColaInteractionGuide`가 Play 시작 시 자동 연결한다. 이 변경은 사용자 직접 확인 대상으로, 에이전트 검증을 실행하지 않았다.
- 자신의 손 동작 이후 보스가 자동으로 행동하며, 보스가 끝나면 다시 선택한다.
- **콜라당 한 번, 내 턴에 원하는 때** 주문서를 사용할 수 있다. 메뉴는 콜라마다 중복 없는 무작위 6종이며 닫았다 열어도 유지된다. 가격 버튼으로 여러 품목·수량을 담고 - 버튼으로 수정한 뒤 아래 ORDER 버튼으로 일괄 결제한다. X/Esc는 미결제 내역만 취소한다. 주문 완료·보스 턴·연출 중 또는 토큰·빈 칸 부족으로 주문할 수 없을 때는 메뉴판이 사라진다. 주문하지 않았다면 이후 자기 턴에 다시 나타난다. 이름/가격에 마우스를 올리면 설명이 나온다. 아이템은 청록색 플레이어 트레이와 붉은 보스 배송 상자에 놓이며 소유자 글자는 사용하지 않는다. 가격·효과·보유 한도는 [Items.md](Items.md)를 따른다.
- 보스도 자기 토큰으로 아이템을 주문·사용한다. 보스 쪽 쟁반의 큐브와 사용 알림, 양쪽 대기 효과로 확인할 수 있다. 보스의 번호표는 플레이어 턴을 한 번 건너뛰게 한다.
- R은 경기 도중에도 전체 진행을 초기화한다.
- 승리 시 NEXT LEVEL 버튼 또는 Enter로 다음 난이도에 도전한다. 패배 시 RESTART RUN 또는 Enter로 처음부터 재시작한다. 새 경기 상태는 검은 화면에서 정리하고 약 0.8초 페이드인 뒤 조작을 연다.

## 임시 경기 규칙

- 플레이어와 첫 보스의 체력은 각각 3이다. 자기 차례에 폭발 판정이 나면 해당 인물의 체력이 1 감소한다.
- 체력이 0이면 즉시 승패를 확정하고 추가 행동을 막는다. 플레이어가 패배한 뒤 보스가 추가로 흔들지 않는다.
- 보스를 격파할 때마다 같은 보스의 최대 체력이 1 증가한다. 최대 99이며, 다음 대전 시작 시 플레이어 체력은 전부 회복한다.
- 안전한 행동은 강도만큼 1·2·3토큰, 폭발한 행동은 강도와 관계없이 **총 5토큰**을 받는다. 양쪽 단말기에 체력과 토큰을 실제 상태로 표시한다.
- 양쪽은 얼음컵과 안전 마개를 1개씩 가지고 시작한다. 플레이어 토큰과 미사용 아이템은 다음 난이도에 이어지고, 새 보스는 토큰 0·시작 아이템 2개부터다. 대기 효과는 다음 난이도에서 초기화한다. 전체 재시작은 난이도 1·토큰 0·양쪽 시작 아이템 2개로 되돌린다. 토큰 상한은 9,999개이며 11종 아이템 주문에 사용한다.
- 새 병의 공개 한계는 **20~30**이다. 폭발 확률은 `min(1, 흔든 뒤 압력 / 한계)`의 **1.5제곱**이며 한계 도달 시 100%다. 초반 확률을 높이기 위해 이전 지수 2에서 낮췄다. 한계 25·현재 압력 5에서는 강도 1/2/3이 11.8%/14.8%/18.1%다. 보스는 임시로 강도 1~3을 무작위 선택하며 아이템으로 그 위험에 대응한다. 매운맛 주문서가 적용된 인물은 다음 실제 흔들기에서 강도 3으로 고정된다.
- 아이템으로 압력·다음 행동·확률·피해·보상을 변경할 수 있다. 기본 폭발 피해는 1이며 핫소스가 붙은 콜라는 2다. 폭발은 원본 손으로 병을 잡고 흔드는 도중 약 0.24초의 압력 고조 뒤 발생한다. 뚜껑·탄산·거품·손 반동·카메라 충격·파열음이 재생되고 손 동작이 끝난 뒤 새 병으로 교체한다. 피해와 토큰은 기존 결과 콜백에서 한 번만 적용한다. 연출 상세는 `Docs/Art/ColaBurst.md`를 따른다.

## 연결과 검증

`08_Devices/DuelRules`의 `ColaDuelController`가 경기 상태와 보상을 관리한다. 기존 `ShakeSelectionInteraction`은 압력·교대 행동, `StatusTerminalDisplay`는 실제 3D 단말기 표시를 담당한다. `ColaDuelHUD`는 차례·결과·조작 안내·다음 경기 버튼만 표시한다.

아웃라인은 원래 키캡/콜라 실루엣을 색 없이 스텐실에 기록한 뒤, 원래 메시를 화면의 상하좌우·대각선 8방향으로 일정 픽셀만큼 옮겨 그린 것 중 마스크 바깥만 남긴다. 각 정점을 중심에서 방사형으로 밀던 방식은 제거해 콜라 바닥의 삼각형이 길게 늘어나 뾰족해지지 않도록 했다. 내부 마스크는 깊이와 무관하게 원래 실루엣 전체를 기록해 앞에 있는 숫자나 불투명 라벨 때문에 빈틈이 생기지 않도록 한다. 버튼 숫자는 색 선 없이 제외 마스크만 추가한다. 콜라는 몸통·뚜껑·라벨 메시를 하나의 마스크 영역으로 합쳐 라벨 표면·글자·안쪽 경계가 노랗게 채워지지 않도록 한다. 색 선 자체는 일반 깊이 검사를 유지해 다른 소품 너머로 비치지 않는다. 원본 재질과 투명도는 바꾸지 않는다. 마스크와 선은 같은 호버 조건으로 켜고 끄며 콜라의 블렌드 셰이프도 함께 따른다. 버튼은 4.5에서 2.5픽셀로 줄였고 콜라는 2.5픽셀을 유지한다. 황금색 명도도 이전에 낮춘 값을 유지한다. 이 수정은 사용자 요청에 따라 검증하지 않았다.

`COLA_COLA > Set Up Playable Duel`은 현재 씬에 해당 연결을 적용한다. 검증은 `PlayableDuelVerification.Begin`으로 Play 모드에서 진행한다. 실제 Raycast 입력, 원본 손 동작의 상태, 보상·피해·사망 후 입력 잠금, 다음 난이도, 중단·재시작 및 두 번째 Play 진입을 검사한다. 결과는 `output/verification/latest/playable-duel/Playmode-validation.txt`와 Unity 로그를 따른다. 별도 카메라나 프리뷰 캡처를 만들지 않으며 자동 검사 통과를 실제 Game 뷰 시각 확인으로 표현하지 않는다.

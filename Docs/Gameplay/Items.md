# 아이템과 웨이터벨

현재 아이템은 **10종, 하나당 효과 하나**다. 핫소스는 양쪽에 적용되는 콜라 효과이며, 팁 봉투는 삭제했다. 회복·방어처럼 경기를 늘리는 품목은 더 낮은 확률로 지급한다. [현재 밸런스](WeightedItemBalance.md)를 따른다.

## 아이템

| 이름 | 효과 | 첫 추첨 확률 |
|---|---|---:|
| 얼음컵 | 압력 -6 | 8% |
| 발포 캔디 | 압력 +6 | 17% |
| 탄산 시럽 | 상대의 다음 흔들기 압력 +3 | 15% |
| 취소 번호표 | 상대 아이템 1개 무작위 제거 | 12% |
| 계산서 | 흔들지 않고 상대에게 차례 넘기기 | 8% |
| 매운맛 주문서 | 상대의 다음 흔들기 압력 2배 | 14% |
| 안전 마개 | 내 다음 흔들기 피해 -1 | 5% |
| 피자 한 조각 | 체력 +1 | 3% |
| 핫소스 | 콜라 교체까지 양쪽 폭발 피해 +1 | 12% |
| 더블 스탬프 | 내 다음 흔들기 보상 +4토큰 | 6% |

시작 아이템과 벨 주문에 동일한 가중치를 적용한다. 한 묶음에서는 중복 없이 추첨하며 두 번째는 첫 품목을 제외한 나머지 가중치로 다시 계산한다. 따라서 위 표는 ‘2개 중 한 번이라도 나올 확률’과 다르며, 묶음 포함 확률은 최신 보고서에 있다. E 테스트 메뉴는 확률과 관계없이 현재 10종을 모두 제공한다.

기존 대기 번호표 모델과 에셋 ID는 유지하고 이름을 **취소 번호표**로 바꿨다. 품목별 옛 가격은 일반 플레이에 쓰지 않는다. 추가 사용료는 없다.

## 공통 규칙

- 전부 일회용이다. 계산서 외의 아이템은 자기 차례를 유지한다. 압력만 바꾸는 아이템으로는 폭발 판정을 하지 않는다.
- ‘다음 흔들기’ 효과는 해당 인물이 실제로 흔들면 한 번에 소모한다. 안전하게 끝나도 소모한다. 계산서나 다른 인물의 행동·병 교체로는 사라지지 않는다. 핫소스는 이 규칙과 달리 **현재 콜라 전체**에 적용한다.
- 같은 대기 효과는 중첩되지 않는다. 적용 중인 효과, 최대 체력에서의 피자, 상대 보관함이 비었을 때의 취소표 등 쓸 수 없는 아이템은 보존한다.
- 피해는 최소 0, 체력은 최대 체력까지다. 마개는 폭발을 막는 대신 피해를 줄인다. 기본 피해 1에 마개가 있으면 0, 핫소스와 마개가 함께 있으면 1이다. 핫소스 사용자는 자기 차례를 유지하므로 자기 위험도 함께 늘어난다. 안전하게 흔들기·계산서·상대 행동으로 해제되지 않으며 콜라 교체 또는 경기 초기화로 해제한다. 같은 콜라에 중첩 사용은 불가능하고 남은 핫소스 아이템은 보존한다.

압력 효과는 **(선택 강도의 압력 + 시럽) × 매운맛 배수**다. 강도 3에 시럽과 매운맛이 함께 있으면 `(8 + 3) × 2 = 22`가 오른다. 스탬프는 안전/폭발 여부와 관계없이 보상에 4를 한 번 더한다. 예: 강도 2 안전 시 6토큰, 폭발 시 9토큰.

## 기본 대전

- 플레이어와 첫 보스는 **체력 6, 토큰 0, 중복 없는 가중 무작위 아이템 2개**로 시작한다.
- 강도 1/2/3의 기본 압력은 **+2/+4/+8**이다. 새 콜라의 공개 한계는 **25~35**다.
- 폭발 확률은 **(흔든 뒤 압력 ÷ 한계)의 1.6제곱**, 한계에 도달하면 100%다. 압력비 20%/50%/80%에서 약 7.6%/33.0%/70.0%다.
- 기본 안전 보상은 1/2/3토큰, 기본 폭발 보상은 총 5토큰이다.
- 보스를 쓰러뜨리면 플레이어 체력을 채우고 잔액·미사용 아이템을 이어간다. 새 보스는 체력 +1, 토큰 0, 새 무작위 시작품 2개다. 대기 효과는 새 경기에서 초기화한다.

## 보관과 주문

양쪽 모두 **8칸(4열×2줄)**이다. 플레이어는 청록색 트레이, 보스는 붉은 배송 상자로 구분한다. 모델에 마우스를 올리면 이름·짧은 효과를 표시하고 자기 모델을 클릭해 사용한다. 소유자나 품목 번호를 띄우지 않는다.

사용 성공 시 실제 소품이 자기 트레이 근처에서 짧게 들려 품목별 동작과 작은 재질음을 재생한 뒤, 크기를 유지한 채 퇴장하며 옅어진다. 약 0.68초의 사용 동작 중에는 다음 사용·강도 선택·흔들기를 잠근다. 보스도 같은 연출을 사용한다. [사용 연출](../Art/ItemUseEffects.md)을 따르며 이번 연출의 Play·컴파일·청취 검사는 실행하지 않았다.

웨이터벨은 테이블 앞쪽 오른편 `(0.29, 0.833, -0.37)`에 있다. **6토큰으로 무작위 아이템 2개**를 받는다. 묶음 안에서는 중복 없이, 기존 보유품과는 겹칠 수 있다. 빈 칸 2개와 6토큰이 모두 필요하며 부족하면 추첨·결제·지급을 하지 않는다. 콜라 교체 때 무료로 추가 지급하지 않는다. [공급 방식 비교](ItemSupplyBalance.md)를 따른다.

경기 중에는 보스 턴이나 흔들기·복귀 연출 중에도 벨을 누를 수 있고 콜라당 제한은 없다. 받은 아이템은 자신의 조작 가능한 차례에 사용한다. 이미 확정된 흔들기 결과를 바꾸지는 않는다. 벨에는 글자판 없이 호버 아웃라인과 하단 설명을 사용한다. 벨 소리는 이전 24kHz·0.5초 합성음이다.

성공한 벨 주문에는 눌림·잔진동과 두 아이템이 차례로 트레이에 착지하는 약 0.61초의 [도착 연출](../Art/ItemUseEffects.md)을 적용한다. 해당 품목은 착지 후 사용할 수 있다. 보스 주문에도 자기 트레이의 도착 연출을 적용하며 실제 결제·추첨·지급은 기존처럼 주문 시 한 번만 처리한다. 이번 연출의 Play·컴파일·청취 검사는 실행하지 않았다.

보스도 같은 가격과 지급 규칙을 사용한다. 자기 준비 구간에 한 묶음까지 주문하고 아이템은 최대 2개 사용한다. 미래 폭발 난수를 읽지 않고 현재 압력·체력·잔액·대기 효과로 판단한다. 발포 캔디 뒤 계산서를 쓰는 조합도 고려한다. 취소표는 아직 보관 중인 아이템만 제거한다.

## 테스트 기능

에디터/Development Build에서만 사용한다. 기본 플레이에는 메뉴판이 없다.

- **Q**: 실제 플레이어 잔액을 999로 설정한다. 벨은 정상 결제한다.
- **W**: 양쪽 폭발 확률 100%를 켜고 끈다. 피해 보정은 유지하므로 마개로 피해를 막을 수 있다.
- **E**: 모든 품목을 무료로 지급하는 테스트 메뉴를 연다. ←/→로 페이지를 바꾸며 보유 한도는 8개다.

좌측 상단의 단축키 안내와 아래의 내 효과·보스 효과를 유지한다. 검증을 요청받았을 때만 공용 경로 `ColaDuelController.ApplyDebugCommand`를 사용하며 사용자 키보드는 조작하지 않는다.

## 구현과 확인 범위

`ColaItemBalance.cs`와 `BottlePressureModel`의 세 압력 값이 수치의 기준이다. `ColaItemCatalog.DropWeight`와 `DrawRandom`이 가중 추첨을 담당한다. `ColaItemController`는 보관·소모·콜라 전체 효과, `ColaDuelController`는 체력·토큰, `ColaBossItemAI`는 보스 판단을 담당한다. 팁 봉투 모델과 제작 코드를 삭제하고 10종 모델을 사용한다.

사용자 요청에 따라 **Unity를 실행하지 않는 가상 대전**을 진행했다. 첫 보스당 5~8분을목표로 조정했다. [현재 가중 확률·핫소스 밸런스](WeightedItemBalance.md)와 [최신 결과](../../output/verification/latest/Summary.md)를 참고한다. `ItemSupplyBalance.md`·`PacingBalance.md`·`ItemBalance.md`는 각 변경 당시 기록이다. Unity Play·컴파일·화면·청취 검사는 실행하지 않았다. 옛 `ColaItemVerification`·`ColaBossItemVerification` 등의 메뉴·턴 생략·확률 감소 검사와 이전 Play 결과는 현재 효과의 통과 근거가 아니다.

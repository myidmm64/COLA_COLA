# 아이템과 웨이터벨

2026-10-19 현재 구현 규칙이다. 이번 변경은 설계와 코드 반영이며, 가상 대전·Unity Play·컴파일 검사는 실행하지 않았다. 이전 비교 보고서의 승률과 경기 시간은 이번 버전의 결과가 아니다.

## 기본 대전

- 플레이어와 첫 보스 체력 6, 토큰 0, 무작위 시작 아이템 2개. 시작품은 중복 없이 뽑으며, 만피에서 쓸 수 없는 피자는 시작 추첨에서만 제외한다.
- 압력 증가량은 강도 1/2/3에서 **2/5/8**. 안전 보상은 **1/2/3토큰**, 폭발 보상은 강도와 관계없이 **총 5토큰**이다.
- 공개 한계 압력은 25~35. 폭발 확률은 `(흔든 뒤 압력 / 한계)²`, 한계 이상이면 100%다. 아이템의 압력 변경 자체는 폭발 판정을 하지 않는다.
- 양쪽 모두 **자기 차례에 아이템 2개까지** 사용한다. 흔들거나 계산서로 차례를 넘기면 종료한다. 벨 주문은 사용 횟수를 쓰지 않는다. 남은 횟수는 해당 차례의 효과 텍스트에 표시한다.
- 터뜨린 쪽이 다음 콜라에서 먼저 행동한다. 새 차례에는 아이템 사용 횟수가 다시 2회가 된다. 단순 병 교체 호출이나 주문으로 횟수를 초기화하지 않는다.
- 보스는 미래 폭발 난수를 보지 않고 공개 압력·양쪽 체력·잔액·대기 효과로 강도를 고르며 아이템 사용 뒤 다시 판단한다. 1단계는 판단 오차가 더 크며 재대전할수록 제한된 범위 안에서 점차 줄어든다.
- 격파 후 플레이어는 회복하고 토큰·미사용 아이템을 이월한다. 보스 체력은 6→7→8까지 증가한 뒤 유지한다. 새 보스는 토큰 0·시작품 2개이며 대기 효과는 초기화한다.

한계 30·현재 압력 10이라면 세 강도의 폭발 확률은 **16% / 25% / 36%**다. 새 콜라에서는 약 **0.4% / 2.8% / 7.1%**다. 이는 계산식의 예시이며 경기 결과를 측정한 수치가 아니다.

## 아이템 10종

| 이름 | 효과 | 벨 첫 추첨 비중 |
|---|---|---:|
| 얼음컵 | 현재 압력 -5 | 9% |
| 발포 캔디 | 현재 압력 +6 | 14% |
| 탄산 시럽 | 상대의 다음 흔들기 압력 +2 | 16% |
| 취소 번호표 | 상대가 보유한 아이템 1개 무작위 제거 | 12% |
| 계산서 | 흔들지 않고 상대에게 차례 넘기기 | 7% |
| 매운맛 주문서 | 상대의 다음 흔들기 압력 2배 | 12% |
| 안전 마개 | 내 다음 흔들기 피해 -1 | 8% |
| 피자 한 조각 | 체력 +1 | 4% |
| 핫소스 | 콜라 교체까지 양쪽 폭발 피해 +1 | 11% |
| 더블 스탬프 | 내 다음 흔들기가 안전하면 +3토큰 | 7% |

시럽과 매운맛은 상대에게 **하나만 대기**할 수 있다. 이미 하나가 적용되어 있으면 다른 하나는 사용되지 않으며 보관함에 남는다. 각 아이템은 단순한 효과 하나를 가지며, 연속 사용은 두 번으로 제한한다.

한 묶음 안에서는 가중 중복 없이 뽑는다. 두 번째는 첫 품목을 제외한 가중치로 다시 추첨하므로 표는 묶음 포함 확률이 아니다. 시작품은 피자를 제외한 합계 96으로 다시 계산한다. 보유 중인 품목과 새 주문 품목은 겹칠 수 있다. 팁 봉투는 지급하지 않는다. E 테스트 메뉴에는 현재 10종이 모두 있고 가격은 무료다.

## 사용과 조합

- 전부 일회용. 계산서 외에는 차례를 유지한다. 아이템 사용 자체는 토큰 보상을 주지 않는다.
- 다음 흔들기 효과는 해당 인물이 실제로 흔들 때 소모한다. 안전해도 소모하고, 스탬프는 폭발하면 추가 보상이 없다. 강도 3 안전+스탬프는 6토큰, 폭발+스탬프는 총 5토큰이다.
- 계산서·상대 행동·병 교체는 다음 흔들기 효과를 지우지 않는다. 핫소스만 현재 콜라에 묶이고 교체 시 해제한다.
- 피해는 기본 1. 마개로 0, 핫소스로 2, 둘을 함께 적용하면 1. 핫소스는 양쪽에 적용되고 중첩 불가다.
- 캔디+계산서는 압력을 높여 넘기기, 마개+핫소스는 자기 위험을 줄인 채 양쪽 피해 높이기, 얼음+스탬프는 안전 보상 노리기라는 서로 다른 용도로 남긴다.
- 적용 중인 효과, 만피에서의 피자, 빈 상대 보관함에 쓰는 취소표, 이미 한계 이상에서의 캔디, 사용 횟수 소진 등 실패 조건에서는 아이템을 소비하지 않는다.

## 보관과 주문

양쪽 트레이는 8칸이다. 청록색이 플레이어, 붉은 상자가 보스다. **6토큰으로 무작위 아이템 2개**를 주문하며, 빈 칸 2개와 잔액이 필요하다. 실패하면 결제·추첨·지급하지 않는다. 새 콜라에서 무료 추가 지급은 없다.

플레이어는 상대 턴과 흔들기 중에도 웨이터벨을 사용할 수 있다. 주문은 이미 확정한 결과를 바꾸지 않는다. 받은 아이템은 착지 후 자신의 조작 가능한 차례에 사용한다. 보스는 자기 준비 구간에 한 묶음까지 주문하고, 양쪽의 가격·지급 규칙·사용 상한은 같다.

상대 턴에도 양쪽 아이템 설명과 효과를 볼 수 있다. 설명은 배경 상자 없이 차분한 회색 글자만 표시한다. 콜라·압력계의 조작 설명과 디버그 안내는 입력 가능한 내 턴에만 표시한다. 콜라를 가리키면 선택한 압력 증가·안전 보상·폭발 보상·피해를 미리 볼 수 있다. 실제 흔들기 중에는 호버로 모델을 들어 올리지 않는다.

아이템 사용과 벨 배송의 기존 모델·연출·소리는 유지한다. [사용 연출](../Art/ItemUseEffects.md)을 따른다.

## 조작과 확인 범위

- Q: 실제 플레이어 토큰을 999로 설정. 벨은 정상 결제.
- W: 양쪽 폭발 확률 100% 전환. 마개·핫소스 피해 보정 유지.
- E: 전체 아이템 무료 테스트 메뉴. ←/→로 페이지 전환, 보유 한도 8개 유지.

디버그는 Editor/Development Build에서만 사용한다. 검증을 요청받았을 때 공용 `ColaDuelController.ApplyDebugCommand`를 사용하고 상태를 복원한다.

첫 보스 5~8분은 설계 목표다. 이번 버전의 경기 시간·승률·체감은 아직 측정하지 않았다. `WeightedItemBalance.md`, `PacingBalance.md`, `ItemSupplyBalance.md`, `ItemBalance.md`와 기존 output 보고서는 과거 규칙의 기록으로 보관한다. 현재 규칙에 맞추지 않은 옛 Python/Editor 진단의 결과를 이번 변경의 검증 근거로 쓰지 않는다.

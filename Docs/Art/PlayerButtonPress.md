# FPS 왼손 압력 버튼 누르기

2026-10-20. 압력 1/2/3 선택 경로에 `ColaPressureButtonPress`를 자동 연결했다. 새 큐브 손 대신 원래 FPS 모델의 `UpperArm.L → LowArm.L → Wrist.L`과 검지 끝 `Index4.L_end`를 사용한다.

- 약 0.30초 동안 왼팔을 곡선으로 뻗는다. 검지는 펴고 나머지 손가락은 가볍게 굽힌다.
- 선택 버튼 Collider의 윗면에 검지 끝을 맞추고, 0.30~0.48초 구간에서 짧게 눌렀다 뗀다.
- 0.48~0.82초 구간에서 원래 대기 자세로 돌아온다. 버튼의 예측 수치와 선택 처리는 기존처럼 즉시 적용한다.
- 같은 압력 버튼을 다시 누르면 선택 상태만 유지하고 손·예측 표시·카메라·클릭음은 다시 재생하지 않는다.
- 빠른 버튼 변경은 마지막으로 표시한 손·어깨·팔꿈치 자세에서 새 버튼으로 전환한다. 처음 뻗을 때만 위쪽 곡선을 사용하며, 재선택은 새 접촉점으로 직접 이동해 연속 입력으로 손 높이가 누적되지 않는다.
- 왼팔 버튼 동작과 오른팔 흔들기는 팔꿈치 굽힘을 사용하지 않는다. `ColaArmPose.Straighten`이 어깨·팔꿈치·손목을 동일한 직선에 배치하고 원래 본 길이를 유지한다. 10도 굽힘과 두 관절 굽힘 IK는 FPS 동작에서 제거했다. 위·아래 팔에는 같은 축 회전량을 적용해 소매 중간이 서로 다른 각도로 비틀리지 않게 한다. 180도 경계에서도 회전 부호가 뒤집히지 않도록 연속 각도를 유지한다. 보스의 원래 관절 동작은 유지한다.
- 곧바로 콜라를 흔들거나 차례를 넘기면 왼손은 약 0.26초 동안 복귀한다. 오른손 흔들기 전에 왼팔 보정을 복원해 흔들기 기준 자세에 누르는 자세가 섞이지 않게 한다.

왼쪽 하위 본만 LateUpdate에서 직선 자세로 보정하고 다음 프레임 평가 전에 원래 로컬 자세를 복원한다. 플레이어 Animator와 오른팔은 계속 기존 동작을 사용한다. 원래 모델의 손가락·소매를 유지한다. 일시적으로 켠 offscreen 갱신은 취소·복귀 때 원래 값으로 돌린다. 재시작·컴포넌트 종료에서도 보정과 임시 상태를 정리한다.

`ColaFpsSleeveExtension`은 원래 FPS 메시에서 어깨 끝부분만 약 42cm 연장한다. 팔꿈치·손목·손가락의 본 길이와 손 형상은 유지한다. 별도 큐브나 보조 팔을 만들지 않는다. 원본 메시·텍스처·본 가중치를 유지한 런타임 메시를 사용하고 종료 시 복원·폐기한다. 이를 위해 원본 FBX의 Read/Write를 켰다.

사용자 요청에 따라 열린 에디터의 Play 모드에서 버튼 접촉·18회 빠른 버튼 변경·같은 버튼 재입력·오른팔 흔들기와 복귀를 검사했다. 실제 Game 뷰 3개 자세는 직접 열어 확인하고, 최신 결과는 `output/verification/latest/arm-motion/`에 둔다. 프리뷰·클립 샘플링·별도 프로젝트·연속 프레임은 만들지 않았다.

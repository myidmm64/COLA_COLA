# 아이템 사용 연출

사용 성공 시 기존 트레이의 실제 모델을 분리해 **0.68초** 동안 **집어 올리기 → 짧은 사용 동작 → 사용자 쪽으로 퇴장**하는 세 구간을 순서대로 재생한다. 양쪽 모두 동일한 경로를 사용한다. 모델·조각은 매 프레임 연속적으로 움직이고, 구간의 시작과 끝을 부드럽게 보간한다. 바닥 원점 대신 실제 모델의 보이는 중심을 회전축으로 사용하며, 크기를 찌그러뜨리거나 0으로 줄이지 않는다. 마지막 약 0.18초만 원본 팔레트를 유지한 전용 재질로 옅어지며 사라진다.

| 품목 | 동작과 소리 |
|---|---|
| 얼음컵 | 콜라 방향으로 짧게 이동해 약 32도 기울이기, 작은 조각·짧은 얼음 부딪힘 |
| 발포 캔디 | 포장을 한 번 작게 비틀기, 포장색 조각·작은 탄산 파열음 |
| 탄산 시럽 | 약 12도 기울여 한 번 누르기, 청록색 방울·낮은 펌프/액체음 |
| 취소 번호표 | 크기 변형 없이 티켓을 작게 비틀기, 종잇조각·종이 찢는 질감 |
| 계산서 | 테이블 앞으로 밀기, 얇은 종잇조각·짧은 종이 마찰음 |
| 매운맛 주문서 | 주문지를 살짝 누르기·접힌 종이 마찰음 |
| 안전 마개 | 한 번 작게 누르기·플라스틱 잠금음 |
| 피자 한 조각 | 자기 트레이 가까이서 들어 올리기, 작은 부스러기·마른 빵/포장지 질감 |
| 핫소스 | 콜라 방향으로 짧게 이동해 약 34도 기울이기, 붉은 방울·짧고 낮은 액체음 |
| 더블 스탬프 | 들어 올려 트레이 가까이 한 번 찍기·낮고 둔탁한 접촉음 |
| 병따개 | 콜라 쪽에서 24도 들어 올리기·짧은 금속 클릭음 |
| 빨대 | 가볍게 기울이기·짧은 흡입 질감 |
| 탄산수 | 콜라 쪽에서 30도 기울이기·방울과 탄산 물소리 |
| 동전컵 | 28도 기울이기·작은 금색 조각과 동전 부딪힘 |
| 교환 집게 | 20도 돌려 짧게 내밀기·금속 집게 클릭음 |

기존 손·보스 본은 변경하지 않고 아이템 소품 자체를 움직인다. 콜라 관련 품목도 수평 이동을 최대 15cm로 제한하고, 나머지는 자신의 원래 칸 근처에서 동작한다. 피자를 카메라 앞으로 끌어오던 경로와 70도 이상의 큰 회전·반복 진동·종이 압축은 제거했다. 실제 입·손·병 뚜껑에 접촉하는 본 애니메이션은 아니다. 컵·소스·캔디·티켓·피자·탄산수·동전컵에만 무광 방울/부스러기를 최대 5개 표시하고, 종이 주문·마개·스탬프가 조각으로 터지는 효과는 사용하지 않는다.

## 연결과 정리

`ColaItemController.EnsureFor`가 `ColaItemUsePresentation`을 자동 연결한다. 성공한 사용은 기존 코드가 효과를 한 번 적용하고 품목을 소모한 뒤 `ItemUsed(id, slot, boss)`를 보낸다. 연출은 효과·보상·추첨을 실행하지 않는다. 무효 사용에는 이벤트를 보내지 않으며 소품도 유지한다.

`ColaItemPresentation.TakeModelForUse`가 슬롯의 실제 모델을 월드 크기 그대로 분리하고 캐시에서 비운다. 인벤토리를 갱신해도 사용 모델이 중복 표시되거나 같은 슬롯에 새로 받은 품목이 연출에 끌려가지 않는다. 효과가 적용된 프레임부터 모델 동작이 끝날 때까지 강도 선택·콜라 확정·추가 사용을 잠근다. 벨은 기존 규칙대로 경기 중 사용할 수 있다. 계산서의 차례 넘김은 기존 경로에서 처리하고, 보스의 다음 사용·흔들기는 진행 중인 연출이 끝날 때까지 기다린다.

소리는 게임 원본 에셋 `SFX_Item_<ID>.wav`를 사용한다. 각 22,050Hz·모노·0.48초이며 품목마다 서로 다른 파형이다. 사용 동작의 중심 시점에 소리와 작은 조각을 함께 재생한다. `ColaTabletopAudio`가 미리 읽은 클립과 재사용하는 AudioSource 풀로 재생한다. 기존 11kHz 런타임 합성 함수와 품목별 임시 클립은 제거했다. 제작 난수는 고정되어 있으며 게임 난수에 영향을 주지 않는다. 프리뷰 파일은 만들지 않는다.

조각은 콜라이더 없는 공유 메시·무광 재질을 풀로 사용한다. 퇴장 투명도는 사용한 소품에만 복제한 재질에 적용하고 원본 아이템/트레이 재질은 건드리지 않는다. 사용한 모델과 퇴장용 재질은 연출이 끝날 때 제거한다. 재시작·다음 경기·액션 취소에서는 공용 오디오도 정지한다. 소유 컴포넌트 파괴 시 메시·재질·런타임 루트를 정리하며 Resources 원본 AudioClip은 파괴하지 않는다.

## 웨이터벨과 주문 도착

플레이어의 벨 주문이 성공하면 누름부를 11mm 눌렀다 복귀시키고, 금속 몸체를 최대 약 1.5도 기울여 짧은 감쇠 잔진동을 보여준다. 클릭 Collider와 배치 기준은 고정한다. 기존 24kHz·0.5초 벨 파형·볼륨은 유지하고, 빠르게 연속 주문하면 벨 전용 소리만 재시작해 중첩되지 않게 했다. 결제나 공간 조건이 맞지 않으면 성공 연출을 시작하지 않는다.

실제 지급 슬롯을 `WaiterOrdered`로 전달해 인벤토리 갱신 직후 해당 두 모델만 움직인다. 각 모델은 오른쪽 위에서 0.46초 동안 들어와 살짝 눌리듯 착지한다. 첫 품목은 0.045초 뒤, 두 번째는 그보다 0.1초 뒤 출발하며 전체 약 0.61초다. 출발 시 종이/트레이 마찰음, 이동 구간의 72% 지점에서 착지음을 각 한 번 재생한다. 컵·시럽·핫소스·탄산수는 유리 질감, 나머지는 둔탁한 접촉음을 사용한다. 도착 연출도 매 프레임 연속 시간과 부드러운 이동 보간을 사용한다. 기존 무광 재질을 사용하고 새 빛·텍스트·파티클은 만들지 않는다.

보스 주문도 자기 트레이에 같은 도착 연출을 적용한다. 플레이어 벨의 소리와 눌림은 플레이어 주문에만 재생한다. 아이템·토큰·추첨은 주문 성공 시 기존 경로에서 한 번만 처리하고, 도착 중인 슬롯은 Collider와 사용 API를 잠근다. 기존 아이템 사용·다른 슬롯·흔들기·경기 중 추가 벨 주문은 기존 조건대로 가능하다. 보스 AI는 자기 도착 연출이 끝난 뒤 품목을 사용한다. E 무료 메뉴와 시작 아이템에는 벨 연출을 재생하지 않는다.

빠른 연속 주문은 새로 지급한 서로 다른 슬롯의 연출만 추가한다. 취소 번호표로 도착 중인 아이템이 지워지거나, 품목 교체·재시작·다음 경기·비활성화가 일어나면 해당 모델의 원래 자세와 클릭 상태를 복원하고 도착 기록을 제거한다. 별도 소품 복제나 프리뷰·검증 결과 파일은 만들지 않았다.

## 확인 범위

사용자 지시에 따라 **Unity Play·컴파일·화면·청취 검사를 실행하지 않았다.** 동작의 실제 위치·소리 크기·인디 분위기는 사용자가 실제 Game 뷰에서 확인해야 한다. 기존 가상 밸런스 결과는 규칙 비교이며 이번 사용 연출이 추가된 실제 경기 시간을 측정한 결과가 아니다.

새 5종은 `compose_tabletop_sfx.py --new-items-only`로 원본 0.48초 WAV·메타데이터만 생성했다. 이번 변경의 Play·청취·컴파일 검사는 실행하지 않았다.

# 콜라 흔들기 — 원본 리그 직접 제어

이전 흔들기 클립 재생, PlayableGraph, 고정된 잡기 자세 위에 덧붙이던 보정, 사인 파형 기반 흔들기를 제거하고 `ColaShakeAnimator`를 새로 작성했다. 도달부터 내려놓기까지 하나의 시간표가 원본 오른팔을 제어한다. 병은 실제 손이 움직인 뒤 그 손의 위치·회전을 따른다.

## 동작 구성

| 기본 시각 | 동작 |
|---|---|
| 0~0.62초 | 현재 Idle 손 위치에서 병 오른쪽으로 완만한 곡선을 따라 손 뻗기 |
| 0.60~0.72초 | 손가락과 엄지 닫기, 실제 접촉 자세에서 손–병 관계를 한 번 기록 |
| 0.72~1.08초 | 병을 들어 몸 쪽으로 약간 당기기 |
| 1.12~2.44초 | 중심 → 뒤/위 → 앞/아래의 명시적 키포즈를 보간해 왕복 |
| 2.44~2.60초 | 흔들림을 가라앉히며 병 확인 자세로 연결 |
| 2.60초 | 공개 압력 비율에 따라 0.45~0.75초 기다린 뒤 결과 공개 |
| 결과 후~3.30초 | 안전하면 테이블 원래 위치까지 내려놓기 |
| 3.30~3.46초 | 손가락 풀기 |
| 3.46~3.95초 | 원래 손 위치로 돌아가기 |

대기 시간은 기본 시각에 추가된다. 폭발하면 동일한 대기 뒤 기존 폭발·암전을 재생하고, 화면이 가려진 상태에서 내려놓기 지점으로 넘어가 손을 복귀시킨다. 안전과 폭발에 따라 대기 자세나 길이를 다르게 하지 않는다.

결과 대기 중에는 독립된 시간으로 손·병의 약 3~4.5mm 이동과 0.9~1.6도 손목 움직임을 계속 갱신한다. 보스 상체에도 아주 작은 움직임을 준다. 흔들기 끝에서 잔동작으로 진입하고, 안전 결과 후 내려놓기 시작 0.18초 동안 잔동작을 부드럽게 풀어 완전히 정지한 프레임처럼 보이지 않게 한다. 원본 리그를 사용할 수 없는 대체 동작에도 같은 종류의 잔움직임을 적용한다. 이번 대기 동작 변경은 Play 검증을 실행하지 않았다.

강도 1/2/3의 왕복은 2/3/4회다. 위아래 키포즈의 편도 목표 이동은 3.5/5.5/7.5cm, 앞뒤 목표 이동은 1.8/3.2/4.5cm다. 손목 굽힘은 플레이어 8/13/18도, 보스 10/18/26도이며 보스는 전체 흔들림을 6% 더 크게 한다. 수평인 캐릭터 오른쪽 축을 중심으로 병을 앞뒤로 기울인다. 각 방향 전환에는 완만한 가감속을 사용한다.

병을 들어 올리면서 각 캐릭터의 오른쪽으로 14도, 몸 쪽으로 6도 기울인 편한 잡기 자세로 전환한다. 손 목표도 오른쪽으로 1.8cm 옮기며, 왕복 방향과 손목 회전축을 이 기울어진 자세에 맞춘다. 양쪽 캐릭터가 각자 방향을 기준으로 사선으로 흔들고, 결과 대기에서도 그 자세를 유지한다. 내려놓을 때는 기울기를 부드럽게 풀어 세운다. 이 사선 자세 변경은 사용자 요청에 따라 Play 검증을 실행하지 않았다. 아래 검증 기록은 변경 전 버전의 확인 범위다.

## 리그와 소유권

플레이어는 원본 FPS `UpperArm.R → LowArm.R → Wrist.R`, 보스는 `upper_arm.R → forearm.R → hand.R`를 사용한다. 손가락 방향과 손등 방향을 실제 본에서 구해 병 옆면을 향하는 자세를 만든다. 오른팔의 두 본 IK가 손 목표를 따르고, 손가락·엄지는 별도의 닫기 동작을 수행한다. 원본 메시·재질·FBX를 바꾸거나 새 팔 모델을 만들지 않는다.

FPS의 앞 방향은 가져온 모델의 피벗 대신 실제 플레이어 카메라를 기준으로 한다. 오른손이 병의 오른쪽에 닿은 뒤 병을 8cm 당겨서 들어 올린다. 원본 FPS 팔은 앉은 자세의 테이블까지 닿기에는 전완 본 길이가 짧다. 손·손가락 크기는 유지하면서 동작 중 전완 도달 길이를 64cm로 보간하고, 팔꿈치를 테이블 위에서 몸 쪽으로 배치한다. 소매를 아래로 밀어 테이블에 파묻히게 하지 않는다. 복귀할 때 원래 본 위치와 길이로 돌아간다. 추가 팔이나 소매 메시를 만들지 않는다. 플레이어의 들어 올린 기준 높이는 강한 흔들림에서도 병 바닥이 테이블에 닿지 않도록 2.5cm 높였다. 보스는 병을 집는 동안 상체를 숙이고 왼손으로 테이블을 지지한 뒤 병을 몸 쪽으로 가져온다.

동작 중에는 행동하는 캐릭터의 Animator를 잠시 멈추고 새 재생기 하나만 뼈를 쓴다. 기다리는 상대는 자기 Animator의 Idle을 계속한다. 모든 본의 기준 로컬 자세를 매 프레임 복원한 다음 새 자세를 계산해 누적 회전이나 이중 제어를 피한다. 원본 SkinnedMeshRenderer는 동작 중 스키닝 갱신을 유지한다. 완료·취소·재시작 시 손/병 자세, 부모, Animator 상태와 메시 갱신 설정을 복원한다.

## 연결

`CanPlay`는 원본 리그 연결만 확인하며 애니메이션 클립을 요구하지 않는다. MainScene에서 이전 12개 클립 연결을 제거했다. `ColaShakeAnimationSceneTools`도 원본 리그 바인딩과 명시적 Play 미리보기만 제공하도록 교체했다. 이전 `ColaShakeAnimationFactory` 제작 코드와 메타 파일은 삭제했다.

`PlayShake(boss, strength, burstPerformance, pressureFraction, safeResult)`는 기존 경기 흐름과 같은 호출 경로를 사용한다. `ActiveHand`, `BottleHeld`, `UsesOriginalRig`, `IsAwaitingResult`, `ShakeStrokeWeight`를 제공한다. 소리·음악·입력 잠금·폭발·피해·토큰 계산은 각각 기존 시스템이 담당하며 표현에서 추가 난수를 소비하지 않는다.

`Assets/_COLA_COLA/Animations/Shake/`에 남은 이전 12개 `.anim`과 메타 12개는 삭제 명령이 도구 정책에 차단되어 원래 위치에 남아 있다. 현재 씬/코드에서는 참조하지 않는다. 다른 삭제 수단이나 이동으로 우회하지 않았다.

## 확인 범위

2026-10-18 사용자의 명시적 요청으로 열린 원본 에디터의 Play에서 반복 확인하며 수정했다. `Tools/Request-UnityVerification.ps1 -Suite shake`는 실제 선택/확정/보스 차례 경로로 양쪽 강도 1/2/3을 실행한다. 손–병 상대 위치와 회전 유지, 본 소유권, 결과 대기, 테이블 높이 여유, W 공용 명령을 통한 양쪽 폭발·복귀, 동작 중 재시작을 확인한다. 일반 흔들림은 W를 끄고 한계를 999로 설정해 애니메이션을 분리해서 검사한다. 확률 밸런스 검사가 아니다.

강도 3의 집기·접촉·두 흔들림 극점·결과 대기·내려놓기·복귀는 Play 중 실제 Game 뷰의 `ScreenCapture.CaptureScreenshot`으로 필요한 자세만 저장해 직접 열어 본다. 별도 카메라나 RenderTexture를 사용하지 않는다. 자동 상태 검사 통과와 화면 자세 관찰은 구분해 기록한다. 결과는 `output/verification/latest/shake-animation/`에 최신 보고서와 필요한 이미지로 모은다.

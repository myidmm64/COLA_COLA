# 피자리아 배경 직원

2026-10-20. `ColaPizzeriaStaff`를 `ColaDuelController.BeginDuel`에서 자동 연결한다. 저장된 MainScene을 수정하거나 에디터를 조작하지 않아도 다음 Play부터 적용되는 구조다.

- 기존 `simple-character-psx_fbx.prefab`을 참조하는 `Resources/PizzeriaStaff.prefab`을 사용한다. 보스의 앉은 자세나 Animator를 복제하지 않고 원본의 서 있는 리그를 사용한다.
- 키는 약 1.66m로 맞춘다. 낮은 채도의 작업복과 앞치마·접은 종이 모자를 더해 보스와 구분한다. 원래 캐릭터 텍스처·본을 유지한다.
- 첫 등장은 시작 후 16~28초, 이후에는 퇴장 후 30~55초 사이. 한 번에 직원 한 명만 등장한다. 왼쪽 작업 공간이 조금 더 자주 선택된다.
- 서비스 카운터 뒤 왼쪽 공간 `(-3.55,0,4.35) → (-1.85,0,4.35)` 또는 오른쪽 공간 `(3.55,0,4.40) → (2.70,0,4.40)`을 약 0.46m/s로 걷는다. 현재 씬의 오븐·음료 기계 사이를 관통하지 않도록 각 측면 작업 구역만 사용한다. 좌표는 현재 MainScene 기준이다.
- 손발을 번갈아 움직이는 걷기, 작은 몸의 흔들림, 부드러운 방향 전환을 적용한다. 작업대에서는 1.8~3.2초 동안 고개를 숙이고 손을 움직인 뒤 돌아간다.
- 어두운 가장자리에서 나타나거나 사라질 때 약한 화면 고정 디더를 사용한다. 직원이 완전히 사라진 픽셀은 깊이를 기록하지 않는다. 별도 그림자·라이트·카메라 효과·텍스트·상호작용 콜라이더는 없다.
- 걸음에 맞춰 작고 둔한 신발 소리를 3D 위치에서 재생한다. 원본 합성 음원 2개를 초기화 때 준비하며 외부 파일은 만들지 않는다. BGM 더킹을 따르고 플레이 동작·폭발 연출 중에는 발소리를 억제한다.
- 흔들기·상대 동작·결과 대기·폭발·암전 중에는 새로 등장하지 않는다. 이미 걷던 직원은 전역 시간을 멈추지 않고 조용히 동작을 이어간다.

등장 시각·방향은 별도의 `System.Random`으로 정하며 아이템·폭발·보스 판단 난수를 소비하지 않는다. 프리팹·메시·머티리얼·음원은 세션 시작 시 준비하고, 출입할 때 재생성하지 않는다. 컴포넌트 종료 시 캐릭터·소리·런타임 메시·머티리얼을 정리한다. 테스트용 이미지·프로젝트 복사본·임시 빌드는 만들지 않았다.

이번 변경의 Play·Game 뷰·청취·셰이더·컴파일 검사는 실행하지 않았다. 동선·직원 밝기·걸음과 발소리의 실제 느낌은 아직 게임 화면에서 확인하지 않았다.

## 복장과 화면 정리

- 복장은 첫 준비 시 원본 SkinnedMeshRenderer의 현재 메시를 메모리에서 읽어 맞춘다. 측정용 메시도 즉시 해제 예약하며 파일로 저장하지 않는다. 앞치마는 가슴·허리·허벅지 관절 높이와 몸의 전면을 기준으로 만든 곡면이다. 상단 폭은 몸 윤곽 안으로 제한하고, 아래 자락은 양다리 사이를 연결한다. 두 어깨 끈과 허리 띠를 추가했다. 허리/몸통 두 관절에 가중치를 줘 작업 자세를 따른다.
- 종이 모자는 머리 윗부분의 폭·깊이와 머리카락 높이로 크기를 정한다. 아랫부분은 머리카락에 살짝 걸치고 위쪽은 좁아지는 8각 접지 형태다. 이 에셋의 `head` 오브젝트는 렌더러이므로 실제 머리 관절인 `spine.005`에 붙인다.
- 직원 셰이더는 고정된 밝기 대신 씬의 환경광과 직접광을 사용한다. 추가 라이트의 Forward/Forward+ 경로를 지원한다. 복장은 양면이며 출입 디더는 유지한다.
- `TabletopReadability`가 다음 Play/대전 시작에 기존 조명 설정을 적용한다. 화면 정리 때 바꿨던 라이트 색·강도·스폿 각도·주방 깜박임·환경광·반사광·안개는 이후 사용자의 "조명만 되돌려줘" 요청으로 모두 이전 값으로 복원했다. 안개 농도는 .065다. 압력계 전용 추가광과 Bloom은 계속 끈다. 직원 복장과 후처리 개선은 유지한다.
- 후처리는 사용자의 복원 요청 후, 효과가 과하다는 후속 요청에 맞춰 정리했다. 원래 조명과 ACES·노출 .40·대비 13·채도 -19·색상 휠은 유지한다. 현재 그레인 .035/응답 .75, 색수차 .004, 비네트 .22/부드러움 .72다. 직원 복장은 유지한다.
- 저장된 후처리 프로필과 씬 제작 도구도 같은 설정을 사용한다. MainScene 파일이나 열려 있는 씬을 강제로 저장하지 않는다.

이 수정의 Play·Game 뷰·컴파일·셰이더 검증은 실행하지 않았다. 실제 복장 관통 여부와 최종 화면 밝기는 사용자의 Play 확인이 필요하다.

## 요청받은 실제 Play 확인 (2026-10-20)

이후 사용자의 Play·캡처 요청으로 원본 MainScene에서 확인했다. 원본 렌더러의 100배 스케일이 측정에 중복 적용되는 것을 발견해 `BakeMesh(mesh, true)`로 보정한 뒤 재실행했다. 실제 흔들기와 보스 행동 2회, 직원의 자연 등장을 확인했다. 최종 모자 크기는 약 .225 × .153 × .178m, 앞치마는 .378 × .617 × .374m다. 실제 Game 뷰 PNG 2개를 열어 전체 조명과 머리 위 모자를 확인했다. 앞치마 대부분은 카운터 뒤에 가려 전체 관통 여부를 시각적으로 확인했다고 주장하지 않는다. 결과는 `output/verification/latest/pizzeria-look/`에 보관했다. 에디터 씬·창 구성을 복원하고 열어 두었다.

## 원본 해상도의 렌즈 효과와 신호 글리치

`ColaRetroRendererFeature`는 PC/Mobile 렌더러의 원본 듀얼 카메라에만 Play 중 적용된다. 사용자의 픽셀라이징 제거 요청에 따라 픽셀 격자·해상도 축소·점 샘플링·혼합 설정을 완전히 제거했다. 현재는 원본 해상도에서 선형 샘플링한다. 필름 노이즈도 .10 → .035로 줄였다. 설명·디버그 텍스트는 이후에 합성한다. 게임 판정·카메라 위치·시간 배율과 원래 조명은 유지한다. 클래스/에셋 이름은 기존 연결을 보존하기 위해 유지한다.

글리치는 RGB 분리를 제거하고 얇은 가로줄 하나의 이동을 약하게 혼합한다. 일반 잡음에서는 중앙 조작부를 보호한다. 첫 일반 잡음은 20초 뒤, 이후 35~55초마다 여유 있는 순간에만 .09초/강도 .10으로 발생한다. 바쁘면 3초 뒤로 연기한다. 결과 대기 때의 별도 잡음은 없앴고, 폭발 때는 .12초/강도 .30이다. sin² 포락선으로 부드럽게 드나들며 전체 픽셀 격자가 튀지 않는다. 전역 밝기 반복 점멸은 없고 스케줄 난수는 게임 판정과 분리한다.

현재 렌즈 마감은 밝은 부분에만 2.5%의 작은 빛 번짐, 가장자리에서 최대 8%의 미세한 부드러움이다. 두 효과는 1.6 원본 픽셀 거리의 공통 4탭을 사용한다. 추가 시도는 고정된 미세 구면 왜곡(.012), 밝은 조명에만 생기는 가로 확산(.018), 결과 대기 때만 가장자리를 최대 5.5% 어둡게 하는 부드러운 비네트다. 가로 확산은 좌우 7/18 원본 픽셀을 샘플링한다. 대기 비네트는 프레임 독립적인 지수 보간으로 드나든다. Bloom 재활성화나 깊이 흐림, 카메라 흔들림·FOV 변화는 추가하지 않는다.

픽셀라이징 제거 전 버전은 실제 Play에서 정상 흔들기와 보스 턴, 일반 잡음, W 공용 경로를 통한 폭발/복귀를 확인했다. 그때 자연 잡음 포착 강도 .078, 폭발 최대 .300/활성 시간 .115초였으며 결과는 `output/verification/latest/retro-screen/`에 있다. 이 보고서와 캡처는 제거 전 버전의 기록이다. 이번 픽셀라이징 제거·새 렌즈 효과는 Play·컴파일·셰이더 검증을 실행하지 않았고, 새 캡처도 생성하지 않았다.

# 채택 아이템 모델

11종을 새로 제작해 양쪽 인벤토리의 임시 큐브를 교체했다. 피자리아의 낡은 종이·무광 포장·플라스틱·소스 병을 기준으로 색과 실루엣을 구분한다. 숫자가 떠 있는 표식은 없고 마우스를 올리면 이름과 효과를 읽을 수 있다.

| 아이템 | 모델 |
|---|---|
| 얼음컵 | 청록색 띠가 있는 다각형 종이컵, 두꺼운 테두리, 각진 얼음 네 조각, 빨간 빨대, 눈송이 인쇄 |
| 발포 캔디 | 붉은 사탕 포장, 양끝을 비튼 크림색 포장지, 청록색 묶음, 번개 표시 |
| 탄산 시럽 | 낮고 넓은 청록색 펌프 병, 검정 누름부와 노즐, 기포 무늬 라벨 |
| 대기 번호표 | 접어 세운 붉은 티켓, 양옆 절취 구멍, 크림색 중앙 면과 턴 넘김 화살표 |
| 계산서 | 작은 검정 받침 위의 기울어진 영수증, 품목/금액 인쇄 줄과 바코드, 금속 집게 |
| 매운맛 주문서 | 붉은 뒷면이 있는 세운 주문지, 검정 집게, 붉은 헤더와 고추 인쇄 |

| 핫소스 | 가늘고 긴 붉은 소스 병, 뾰족한 빨간 뚜껑, 크림색 고추 라벨 |
| 더블 스탬프 | 나무 직사각형 받침, 붉은 고무 면, 금속 목과 다각형 붉은 손잡이, 이중 인쇄 표시 |
| 팁 봉투 | 접힌 선·삼각 덮개·봉인이 있는 크라프트 봉투, 위로 보이는 금색 동전 두 개 |

## 에셋과 연결

원본 모델은 `Assets/_COLA_COLA/Resources/ItemModels/01_IceCup.obj`부터 `11_TipEnvelope.obj`까지의 11개 OBJ다. 미터 단위, Y축 위쪽, 바닥 원점, 평면 노멀을 사용한다. 각 모델은 하나의 메시로 만들고 64×32픽셀 `PizzeriaItemPalette.png`의 24색을 UV로 공유한다. 외부 텍스처·폰트·머티리얼 파일을 요구하지 않는다.

`Tools/Art/build_item_models.py`는 원본 에셋 제작 스크립트다. 재실행하면 같은 경로의 11개 메시와 팔레트를 갱신한다. Unity 실행·검증·프리뷰 생성 기능은 없다. 원본 파일과 안정된 GUID 메타데이터만 보관한다.

`ColaItemModelLibrary`가 구매 품목에 맞는 모델을 불러와 무광 URP Lit 머티리얼 하나를 공유시킨다. `ColaItemPresentation`은 양쪽 각 6칸의 위치를 유지하고 실제 품목이 바뀔 때만 모델을 교체한다. 비어 있는 칸은 입력과 모델을 함께 숨긴다. 인스턴스와 런타임 머티리얼은 소유 컴포넌트가 정리한다.

클릭은 모델 전체 경계에 작은 여유를 둔 슬롯 BoxCollider로 처리한다. 얇은 종이·피자도 누르기 쉽게 최소 클릭 크기를 두고, 개별 인쇄나 작은 부품이 입력을 가로채지 않게 한다. `ColaItemCube`/`CubeCollider`라는 기존 코드 이름은 입력·소유권 연결 호환용으로 유지하며 화면에 큐브를 그리지 않는다. 아이템 효과·가격·주문 규칙은 변경하지 않았다.

## 화면 표시

플레이 중 상단 레벨/차례 바, 하단 결과/조작 안내 바, 보스 아이템 사용 알림 패널을 제거했다. 화면 아래에는 배경 패널 없이 **내 효과**, **보스 효과** 두 줄만 상시 표시한다. 마우스로 가리킨 아이템의 이름·효과 툴팁과 중앙 승패/다음 경기 버튼은 유지한다. 체력과 토큰은 실제 단말기 모델로 확인한다.

이 변경은 사용자 요청에 따라 Play·컴파일·자동 검증을 실행하지 않았다. 실제 Game 뷰에서의 모델 가독성·가림·클릭 동작은 확인하지 않았으며 기존 검증 보고서는 이 변경 전 결과다.

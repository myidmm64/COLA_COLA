# 채택 아이템 모델

현재 15종의 모델로 양쪽 인벤토리의 임시 큐브를 교체했다. 피자리아의 낡은 종이·무광 포장·플라스틱·소스 병을 기준으로 색과 실루엣을 구분한다. 숫자가 떠 있는 표식은 없고 마우스를 올리면 이름과 효과를 읽을 수 있다.

| 발포 캔디 | 붉은 사탕 포장, 양끝을 비튼 크림색 포장지, 청록색 묶음, 번개 표시 |

## 에셋과 연결

원본 모델은 `Assets/_COLA_COLA/Resources/ItemModels/01_IceCup.obj`부터 `15_SwapTongs.obj`까지의 15개 OBJ다. 미터 단위, Y축 위쪽, 바닥 원점, 평면 노멀을 사용한다. 각 모델은 하나의 메시로 만들고 64×32픽셀 `PizzeriaItemPalette.png`의 24색을 UV로 공유한다. 외부 텍스처·폰트·머티리얼 파일을 요구하지 않는다.

`Tools/Art/build_item_models.py`는 원본 에셋 제작 스크립트다. 재실행하면 같은 경로의 15개 아이템 메시·웨이터벨 본체/누름부 2개 메시·공용 팔레트를 갱신한다. Unity 실행·검증·프리뷰 생성 기능은 없다. 원본 파일과 안정된 GUID 메타데이터만 보관한다.

`ColaItemModelLibrary`가 구매 품목에 맞는 모델을 불러와 무광 URP Lit 머티리얼 하나를 공유시킨다. `ColaItemPresentation`은 양쪽 각 **8칸(4열×2줄)**에 실제 품목이 바뀔 때만 모델을 교체한다. 칸 간격은 0.17m, 원본 트레이 폭은 0.72m로 넓혔으며 아이템 크기와 84% 배율은 유지한다. 양쪽 중심을 오른쪽으로 3.5cm 옮겨 왼쪽 캐릭터와의 간격을 확보하는 방향으로 배치했다. 비어 있는 칸은 입력과 모델을 함께 숨긴다. 인스턴스와 런타임 머티리얼은 소유 컴포넌트가 정리한다.

클릭은 모델 전체 경계에 작은 여유를 둔 슬롯 BoxCollider로 처리한다. 얇은 종이·피자도 누르기 쉽게 최소 클릭 크기를 두고, 개별 인쇄나 작은 부품이 입력을 가로채지 않게 한다. `ColaItemCube`/`CubeCollider`라는 기존 코드 이름은 입력·소유권 연결 호환용으로 유지하며 화면에 큐브를 그리지 않는다. 현재의 단일 효과와 획득 규칙은 [아이템 문서](../Gameplay/Items.md)를 따른다.

웨이터벨은 이전 위치에서 왼쪽으로 8cm 옮긴 **`(0.29, 0.833, -0.37)`**에 둔다. 다각형 금속 돔·황동 띠·어두운 받침이 있는 `WaiterBell.obj`와 따로 움직이는 `WaiterBellPlunger.obj`를 사용한다. 앞 가격판과 글씨는 없으며 실제 벨 형상에 맞게 클릭 범위도 줄였다. 마우스를 올리면 2.5픽셀 황금색 외곽선과 화면 하단 설명을 표시한다. 잔액·공간 부족 시에도 설명을 볼 수 있다. 실제 주문 성공 시 누름부를 9mm 눌렀다 복귀하고 짧은 합성음을 재생한다. 일반 메뉴판은 숨겨져 있고 E 무료 테스트 모드로만 볼 수 있다. 이 모델·배치는 Play 검증을 실행하지 않았다.

## 화면 표시

벨 소리는 사용자 요청으로 이전의 **24kHz·0.5초 런타임 합성음**으로 되돌렸다. 1,480 / 2,353 / 3,517Hz의 세 금속 배음을 빠르게 감쇠시키며 재생 볼륨도 이전 값 0.48을 사용한다. 음원 파일이나 미리듣기 파일은 생성하지 않았고 청취 검증은 실행하지 않았다.

벨 설명·아이템 툴팁은 기본/호버/누름/포커스 상태 모두 같은 아이보리 글자색을 사용한다. GUI 스킨에서 상속된 흰색 호버 색을 제거하고 GUI의 전역 틴트도 표시 구간에서 고정한다. 텍스트 색상 페이드나 전환은 사용하지 않는다. 벨 설명의 가독성용 어두운 그림자는 고정 색으로 유지한다.

플레이 중 상단 레벨/차례 바, 하단 결과/조작 안내 바, 보스 아이템 사용 알림 패널을 제거했다. 화면 아래에는 배경 패널 없이 **내 효과**, **보스 효과** 두 줄만 상시 표시한다. 마우스로 가리킨 아이템의 이름·효과 툴팁과 중앙 승패/다음 경기 버튼은 유지한다. 체력과 토큰은 실제 단말기 모델로 확인한다.

이 변경은 사용자 요청에 따라 Play·컴파일·자동 검증을 실행하지 않았다. 실제 Game 뷰에서의 모델 가독성·가림·클릭 동작은 확인하지 않았으며 기존 검증 보고서는 이 변경 전 결과다.

`build_item_models.py --new-items-only`는 새 5종만 제작한다. 이번에는 원본 OBJ·안정된 GUID 메타데이터와 게임용 사용음만 추가했으며 프리뷰나 Play 검증 결과를 만들지 않았다.

# 상호작용 카메라

2026-10-20. 대기 중 카메라는 고정한다. 상대 행동의 카메라 반응은 끄고, 압력 버튼에는 작은 끄덕임을 사용한다.

- 보스 턴 전환, 보스 흔들기·잡기·내려놓기·안전 확인, 보스 아이템 사용·배송·병 교체의 추가 카메라 반응을 제거했다.
- 압력 버튼 1/2/3은 모두 0.48초의 반응을 사용한다. 직전 미세 설정보다 약 4배 키웠다. 기본 강도에서 보간 전 최대 피치 약 0.078/0.098/0.117도, 전진 약 1.76/2.08/2.41mm다. 같은 버튼 재입력은 반응을 반복하지 않는다.
- 내 벨·아이템·배송·콜라 잡기와 내려놓기에는 작은 전후 이동을 유지한다. 회전은 상하 최대 0.27도·좌우 최대 0.40도이며 롤은 0이다. 일반 위치 목표는 최대 9mm다. 버튼만을 위한 상한 확대는 제거했다.
- 내 흔들기는 손의 실제 왕복 값 `ColaShakeAnimator.ShakeStroke`를 따라 상하·전후 이동과 피치를 더한다. 강도 1/2/3에서 움직임이 커지며 잡아 올릴 때 전방 이동은 4mm다. 흔들기 구간은 최대 16mm·피치 0.50도까지 허용하며, 시작과 끝 0.10초에 부드럽게 진입·복귀한다. 상대 흔들기, 좌우 왕복과 롤은 추가하지 않는다.
- 버튼·병·벨·배송·메뉴·아이템의 여섯 계열은 각각 진행 중인 카메라 반응을 끝까지 유지한다. 연속 입력으로 기존 반응을 덮어쓰거나 타이머를 처음부터 돌리지 않는다. 담기·실패 클릭의 미세 반동도 없다.
- 최종 카메라 위치·각도 목표를 0.055초 SmoothDamp로 이어 붙이며 속도도 유지한다. 이벤트 강도는 선형 시각의 사인 곡선을 쓰고, 시작 시각을 다시 SmoothStep으로 느리게 만드는 중복 완화를 제거했다. 동작 종료나 다른 상호작용 시작 때 영점으로 초기화하지 않는다. Cinemachine의 한 프레임 중복 평가에서도 보간은 한 번만 진행한다. 명시적 게임 초기화 때만 전체 상태를 비운다.
- 카메라 반응은 행동 주체를 따로 전달한다. 상대 턴에 내가 누르는 벨이나 내 배송까지 차단하지 않는다. 소리는 기존 경로를 유지한다.
- 폭발은 상대 일반 움직임과 별개로 짧은 반동을 유지한다. `ColaBurstCameraImpulse`의 빠른 좌우 진동·요·롤을 제거하고 최대 4cm 후퇴·2.2도 피치의 단일 반동을 0.65초 안에 감쇠시킨다. 보스 쪽 폭발 반동은 기존 62% 배율이다.

`ColaInteractionCamera`는 `07_Cameras/CM_SeatedDuel`의 Cinemachine Noise 단계 보정으로 동작하며 앵커·캐릭터 본·FOV를 직접 변경하지 않는다. `ColaCameraBreathing`은 저장된 씬 참조를 유지하되 자동 비활성화하고 보정 출력을 0으로 유지한다. 일반 움직임은 파열·암전 구간에서 억제하고 재시작·취소 때 초기화한다.

이번 조정은 사용자의 명시적 요청에 따라 열린 원본 에디터의 Play 모드에서 검사했다. `output/verification/latest/arm-motion/`에 실제 Game 뷰의 버튼 접촉·오른팔 흔들기·복귀 자세 3장과 최신 기록만 유지한다. 대기 카메라 고정, 같은 선택의 애니메이션 중복 방지, 18회 빠른 재선택, 팔 본 길이 유지, 실제 오른팔 동작 완료를 검사한다. 상태 검사와 별도로 Game 뷰 이미지를 열어 소매의 모양과 끝부분을 확인한다. 프리뷰 카메라·Camera.Render·연속 프레임은 사용하지 않는다.

왼손 버튼 동작은 [PlayerButtonPress.md](PlayerButtonPress.md)를 따른다. 게임 BGM은 Bleak Terminal 단독이며, 외부 추가 후보는 `References/BGM_Candidates/README.md`에 있다.

## 시작 지연 수정 / 실제 Play 계측

2026-10-20. 버튼 카메라의 시작 완화가 중복되고 첫 콜라 흔들기에서 폭발용 텍스처·파티클·합성 소리를 생성하고 있었다. 카메라 이중 완화를 제거하고, 결과가 결정되기 전 게임 세션 초기화에서 효과 리소스와 왼팔 본 연결을 미리 준비한다. 새로운 효과를 재생하거나 게임 난수를 소모하지 않는다. 기존 결과 확인 대기와 폭발 연출은 유지한다.

열린 원본 에디터에서 같은 입력을 두 번 측정했다. 첫 이동 판정 기준은 실제 카메라 위치 변화 0.01mm 이상이다.

벨·잡기 카메라 곡선도 따로 측정했다. 실제 벨 구매 검사와는 구분한다. 계측 동안 캡처·파일 쓰기·메시 굽기를 실행하지 않았고, 측정이 끝난 후 최신 로그만 `output/verification/latest/camera-motion/`에 저장했다. 상태·프레임 측정 결과이며 연속 Game 뷰의 시각적 부드러움을 직접 관찰했다는 의미는 아니다. 수치는 해당 에디터 세션의 측정값이며 하드웨어별 보장을 뜻하지 않는다.

# 테이블 효과음

`ColaTabletopAudio`가 대전의 압력 조작 컴포넌트에 자동 연결된다. 원본 WAV는 `Assets/_COLA_COLA/Resources/Audio/SFX_*.wav`, 제작 소스는 `Tools/Audio/compose_tabletop_sfx.py`다. 파일 29개를 제작했다. 모두 직접 합성한 22,050Hz·모노·16bit 음원이며 게임 난수와 무관하다.

| 동작 | 소리 / 연결 시점 |
|---|---|
| 얼음컵 | 세 번의 얼음 접촉과 짧은 물 흐름 |
| 발포 캔디 | 포장 파열과 짧은 탄산 알갱이 |
| 탄산 시럽 | 펌프 접촉과 묽은 액체 흐름 |
| 취소 번호표 | 날카로운 종이 찢김 |
| 계산서 | 종이 밀기와 테이블 접촉 |
| 매운맛 주문서 | 두 번의 종이 접힘과 눌림 |
| 안전 마개 | 작은 플라스틱 클릭과 잠금 |
| 피자 한 조각 | 마른 빵/포장지 바스락거림 |
| 핫소스 | 뚜껑 접촉과 걸쭉한 소스 분출 |
| 더블 스탬프 | 낮은 고무/나무의 이중 접촉 |
| 벨 주문 도착 | 모델 출발 마찰음, 트레이 착지음. 유리/일반 재질 구분 |
| 강도 버튼 | 성공한 선택과 재선택에 기계식 클릭 |
| 콜라 | 집기, 압력별 흔들기, 내려놓기, 안전 후 짧은 탄산 잔향, 새 병 배치 |
| 기타 | 토큰 획득, 보스 차례 시작, 사용/주문 불가, 승리/패배 |
| E 테스트 메뉴 | 열기/닫기, 페이지 넘김, 담기/빼기, 주문 완료 |

흔들기는 1초 루프 세 개를 같은 DSP 시각에 시작한다. 확정 후 실제 압력/한계 비율을 기준으로 0% 저압 → 50% 중압 → 100% 고압을 등전력 크로스페이드한다. 저압은 액체 출렁임, 고압은 더 거친 탄산·플라스틱 마찰음이다. 강도 1/2/3에 따라 피치를 0.94~1.12로 바꾼다. 애니메이터의 실제 재생 시각을 읽어 1.42~2.43초 흔들기 구간에만 루프를 올리고 앞뒤는 짧게 페이드한다. 폭발 직전부터 루프를 내리며 기존 폭발음을 가리지 않는다. 보스도 같은 경로를 사용한다. 애니메이션이 없는 폴백은 기존 흔들기 지속시간을 따른다.

기본 효과음 게인은 0.78이다. 사전 로드 클립, 단발용 12개 AudioSource와 흔들기용 3개 AudioSource를 재사용한다. 효과음 이벤트마다 오브젝트/클립을 만들지 않는다. 새 경기·액션 취소·비활성화 시 재생을 정지하고 파괴 시 런타임 루트를 제거한다. 기존 벨 파형, 폭발·뚜껑·압력 파열음 및 피자리아 환경음은 유지한다.

이번 변경은 원본 음원 제작과 연결까지만 진행했다. 사용자 지시에 따라 Play·컴파일·청취 검증은 실행하지 않았다. 이전 music 검증 결과는 이번에 다시 만든 곡과 효과음의 검증 근거가 아니다.

# 손에 든 콜라의 폭발

MainScene의 실제 흔들기 결과가 폭발일 때 `ColaBurstPresentation`이 동작한다. `ShakeSelectionInteraction`이 Play 진입 시 자동 연결하므로 기존 씬을 재생해도 적용된다. 연출은 아이템·압력 규칙과 분리한다. 2026-10-20 폭발 대비·저음·분출·반동을 강화했다.

## 연출 순서

1. 기존 FPS 팔 또는 보스의 원본 오른손으로 병을 잡고 흔든다. 압력에 따른 기존 흔들기 소리와 결과 공통 대기를 유지한다.
2. 손에 병을 든 결과 대기 이후 약 0.30초의 압력 파열 예고를 넣는다. 병은 최대 6.5% 부풀고, 후반에는 PET 마찰음·BGM·환경음이 내려가 잠깐 정적을 만든다.
3. 짧은 파열음·48Hz 저음·하강하는 폭음·35/77ms 반사음·작은 고음 잔향을 겹친다. 0.12초 이내의 한 번의 섬광·광원 펄스와 최대 1.55m 충격파를 동기화한다. 원본 뚜껑과 콜라·거품·분무 408개, 압력 코어/짙은 증기 72개, PET·라벨 조각 28개의 수는 유지하면서 크기·속도를 높인다. 첫 0.09초 동안 파티클만 30% 속도로 보여 주고 정상 속도로 분출을 잇는다. Time.timeScale·팔·카메라는 멈추지 않는다. 외부 이미지·오디오 파일은 생성하지 않는다.
4. 손의 반동과 보스 상체의 짧은 젖힘을 강화한다. 플레이어 팔꿈치는 직선 연결을 유지한다. 카메라는 위치 목표 약 6.3cm·피치 2.9도 이내의 한 번의 후퇴로 충격을 주고 0.78초 안에 감쇠한다. 보스 폭발은 62% 강도다. 섬광 뒤에는 얕은 화면 명도 감소와 가장자리 렌즈 물방울이 남는다. 반복 섬광·좌우 진동·롤은 추가하지 않는다.
5. 파열과 분출을 조금 더 보여 준 뒤, 폭발 후 0.44~0.66초에 화면을 완전히 검게 만든다. 손의 복귀 구간 이동·Idle 복원·원본 병 교체·체력과 토큰 적용은 검은 화면 아래서 처리한다. 피해·보상은 기존 콜백으로 한 번만 적용한다.
6. 남은 파편·뚜껑·충격파·렌즈 얼룩과 카메라 충격을 검은 화면에서 정리하고 0.22초 동안 실제 Animator·Cinemachine·단말기 상태를 안정시킨다. 이후 **0.38초 SmoothStep 페이드인**으로 새 콜라와 게임 화면을 드러낸다. 기존 0.82초보다 짧게 전환하며 화면 아래의 복원 순서는 유지한다. 전환이 끝날 때까지 입력과 다음 인물의 행동을 잠근다. 치명적 폭발도 같은 전환 뒤 승패 화면을 보여 준다.
7. 승리 후 NEXT LEVEL/Enter로 다음 난이도를 시작하거나 패배 후 RESTART RUN/Enter로 다시 시작할 때도 동일한 암전·페이드인을 적용한다. 진행 중 R로 연출을 취소할 때는 잔여 암전을 즉시 제거한다.

## 구성

- `ColaBurstPresentation`: 월드 파티클·충격파 메시·짧은 광원 펄스, 원본 뚜껑 표시 전환과 탄도 비행, 테이블 액체 충돌 평면, 자국·렌즈 효과, 화면 섬광·암전·페이드인. 광원은 폭발 순간에만 켜지고 전환 전에 꺼져 압력계 조명이 밝게 남지 않는다.
- `ColaBurstCameraImpulse`: Cinemachine Noise 단계 보정. 기준 카메라 Transform·FOV·전역 시간 배율을 바꾸지 않는다. 0.78초 안에 감쇠한다.
- `ColaBurstAudio`: 고정된 별도 난수로 생성하는 원본 합성 효과음. PET 긴장음, 파열·분출·잔향, 뚜껑 소리의 임시 음원이다. 흔들기 클립 생성과 루프 재생은 제거했다. 외부 파일·게임 판정 난수·전역 오디오 볼륨을 사용하지 않는다.
- `ColaShakeAnimator`: 기존 재생 경로의 선택적 폭발 콜백. 손에 잡힌 구간에서만 잠깐 재생 시간을 유지하고 원본 팔에 반동을 더한 뒤 복귀 구간으로 이어간다. 안전한 행동과 단독 애니메이션 미리보기는 기존 경로다.
- `Resources/COLA_COLA_Spray.shader`: URP용 비발광 소프트 마스크 셰이더. 빌드에서도 Resources를 통해 참조된다.

재시작·상호작용 비활성화·다음 난이도는 진행 중 연출, 소리, 파티클 속도, 뚜껑 복제본, 렌즈 효과, 카메라 충격과 암전/페이드를 취소한다. 원본 병의 부모·위치·크기와 뚜껑 표시를 복원하며 지연 피해·보상은 발생시키지 않는다. 임시 메시·텍스처·클립은 세션 초기화에서 미리 준비한다. 파열 프레임에 새 합성 음원이나 텍스처를 생성하지 않는다.

## 검증

이번 폭발 강화 변경의 Play·청취·컴파일 검사는 실행하지 않았다. 기존 폭발 보고서는 이번 변경 전 결과다.

`COLA_COLA > Verify Cola Burst In Play Mode` / `ColaBurstVerification.Begin`으로 실제 Play 모드에서 검사한다. 양쪽 실제 Raycast 입력·원본 손의 접촉 구간·파티클/뚜껑·섬광/충격파·카메라 보정·안전 행동·피해/보상을 다룬다. 검은 화면에서 교체와 콜백이 일어나는지, 페이드 알파가 단조롭게 감소하는지, 복원 완료 뒤에만 화면과 조작이 돌아오는지, 파열/페이드 도중 재시작이 잔여 암전이나 잠금을 남기지 않는지도 검사한다. 치명적 폭발 후 승패와 다음 난이도를 포함한다. `output/verification/latest/cola-burst/Playmode-validation.txt`와 최신 Unity 로그가 결과다.

자동 상태 검사는 실제 Game 뷰의 시각적 완성도나 효과음을 청취한 검증을 대신하지 않는다. 별도 프리뷰 카메라·렌더 캡처·연속 프레임은 만들지 않는다.

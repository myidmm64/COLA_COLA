# 손에 든 콜라의 폭발

MainScene의 실제 흔들기 결과가 폭발일 때 `ColaBurstPresentation`이 동작한다. `ShakeSelectionInteraction`이 Play 진입 시 자동 연결하므로 기존 씬을 재생해도 적용된다. 아이템·주문 기획과는 별개이며 압력 한계 20~30, 확률 지수 1.5, 피해 1, 폭발 시 총 5토큰 규칙은 유지한다.

## 연출 순서

1. 기존 FPS 팔 또는 보스의 원본 오른손으로 병을 잡고 흔든다. 안전한 행동에는 작은 액체 흔들림 소리만 더한다.
2. 손으로 잡은 구간 약 2.45초에서 폭발 연출을 시작한다. 약 0.24초 동안 병 옆면이 최대 3.5% 부풀고 PET 마찰·압력음이 올라온다.
3. 파열음에 맞춰 기존 뚜껑 메시의 시각 복제본이 튀고, 갈색 콜라 방울·밝은 거품·엷은 분무 408개가 퍼진다. 약 0.4초의 추가 분출을 이어간다. PET 병이므로 불꽃·연기·유리 파편은 넣지 않는다.
4. 원래 팔의 짧은 반동, Cinemachine의 감쇠하는 위치·회전 충격, 테이블 위 젖은 자국, 뚜껑 착지음을 더한다. 플레이어 폭발은 더 강한 충격과 가장자리 렌즈 물방울을 쓰고, 보스 폭발은 작은 충격만 쓴다.
5. 약 1초의 분출·회복 뒤 기존 손 복귀 동작을 이어간다. 새 병으로 교체한 뒤 기존 콜백으로 피해·토큰을 한 번 적용하고 다음 차례를 진행한다.

## 구성

- `ColaBurstPresentation`: 월드 공간 파티클, 원본 뚜껑 표시 전환, 탄도 비행, 테이블 액체 충돌 평면, 짧은 자국·렌즈 효과. 파티클은 비발광 알파 블렌딩이다. 조명·블룸·압력계 재질을 밝히지 않는다.
- `ColaBurstCameraImpulse`: Cinemachine Noise 단계 보정. 기준 카메라 Transform·FOV·전역 시간 배율을 바꾸지 않는다. 약 0.85초 안에 감쇠한다.
- `ColaBurstAudio`: 고정된 별도 난수로 생성하는 원본 합성 효과음. 병 내부 액체, PET 긴장음, 파열·분출·잔향, 뚜껑 소리의 임시 음원이다. 외부 파일·게임 판정 난수·전역 오디오 볼륨을 사용하지 않는다.
- `ColaShakeAnimator`: 기존 재생 경로의 선택적 폭발 콜백. 손에 잡힌 구간에서만 잠깐 재생 시간을 유지하고 원본 팔에 반동을 더한 뒤 복귀 구간으로 이어간다. 안전한 행동과 단독 애니메이션 미리보기는 기존 경로다.
- `Resources/COLA_COLA_Spray.shader`: URP용 비발광 소프트 마스크 셰이더. 빌드에서도 Resources를 통해 참조된다.

재시작·상호작용 비활성화·다음 난이도는 진행 중 연출, 소리, 파티클, 뚜껑 복제본, 렌즈 효과, 카메라 충격을 취소한다. 원본 병의 부모·위치·크기와 뚜껑 표시를 복원하며 지연 피해·보상은 발생시키지 않는다. 임시 메시·텍스처·클립은 런타임에만 생성한다.

## 검증

`COLA_COLA > Verify Cola Burst In Play Mode` / `ColaBurstVerification.Begin`으로 실제 Play 모드에서 검사한다. 양쪽 실제 Raycast 입력·원본 손의 접촉 구간·파티클/뚜껑·카메라 보정·안전 행동·피해/보상·도중 재시작·치명적 폭발 후 승패와 다음 난이도를 다룬다. `output/cola-burst/Playmode-validation.txt`와 Unity 로그가 결과다.

자동 상태 검사는 실제 Game 뷰의 시각적 완성도나 효과음을 청취한 검증을 대신하지 않는다. 별도 프리뷰 카메라·렌더 캡처·연속 프레임은 만들지 않는다.

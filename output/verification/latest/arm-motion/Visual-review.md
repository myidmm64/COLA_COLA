# 실제 Play / Game 뷰 확인

2026-10-20. 요청 ID: `shake-arms-fccada5a3a1c414681b43468319786a0`. 팔꿈치를 약하게 굽히던 이전 방식은 폐기하고 FPS 양팔을 직선으로 고정했다.

열린 원본 Unity 에디터의 Play 모드에서 조작 경로를 실행하고, ScreenCapture가 저장한 실제 Game 뷰의 아래 세 이미지를 직접 열어 확인했다. 프리뷰 카메라·Camera.Render·클립 샘플링은 사용하지 않았다.

- `Left-press.png`: 원래 FPS 왼손이 버튼에 닿는다. 손목에서 화면 밖 팔 끝까지 소매를 일직선으로 잇는다.
- `Right-shake.png`: 원래 오른손으로 콜라를 잡는다. 팔꿈치 굽힘 없이 소매를 화면 아래까지 일직선으로 잇고, 어깨 쪽 잘린 단면이 화면 안에 노출되지 않는다.
- `Right-return.png`: 오른손 복귀 중 소매가 화면 아래로 이어진다. 손목과 소매가 끊어져 보이는 틈은 확인한 자세에서 보이지 않는다.

자동 Play 기록: 대기 2초 동안 카메라 이동 0m·회전 0도. 버튼 카메라 최대 이동 약 0.83mm. 같은 버튼 재입력이 누름 타이머를 재시작하지 않음. 18회 빠른 재선택 완료. 양팔 본 길이 오차 0.0000004m 이하. 확인한 세 자세에서 오른팔 어깨 끝 정점 20개 모두 Game 뷰 밖. 오른팔 흔들기·복귀 완료, 원래 Animator 제어 복원.

모든 표본 활성 애니메이션 프레임에서 어깨·팔꿈치·손목의 일직선 정렬을 별도로 검사했고 굽힘각은 0.15도 미만이었다. 본 길이는 유지한다. 로그의 전체 구간 최대 굽힘에는 동작 종료 후 원래 Idle 자세도 포함되며, 활성 동작은 별도 직선 조건을 통과했다. 가장 큰 프레임 간 회전값에는 Game 뷰 캡처로 길어진 프레임이 포함된다. 50ms 미만의 일반 프레임에서 오른팔 최대 회전 변화는 약 10.21도였다. 연속 영상 전체의 실시간 시청이나 모든 해상도에서의 외형 확인으로 확대 해석하지 않는다.

W는 끄고 동작을 격리했으며 Q/E는 불필요해 사용하지 않았다. 검사 전 디버그·자동 보스 설정을 기록하고 복원했다. 게임 확률 밸런스 검사가 아니며, 확인용 압력 한계 999는 Play 종료 후 남지 않는다. 원래 씬 구성·Game 뷰 최대화 상태·포커스를 복원하고 에디터는 열어 두었다.

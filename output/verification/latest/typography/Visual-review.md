# Terrarum Sans Bitmap 가독성 확인

2026-10-19, 실행 `fonts-52badb2398934525ba4a65e7b40af6bd`. 열린 원본 Unity 에디터 PID 33256, MainScene의 실제 Play Game 뷰 1351×760에서 확인했다.

## 변경 전 관찰과 수정

변경 전 Game 뷰에서 작은 UI 글자의 획이 끊겨 보였고, 메뉴판 가격·보조 글자는 작아서 읽기 어려웠다. Point 필터와 작은 12~18px 화면 글리프, 임의 크기의 48/64px 월드 글리프를 함께 사용하고 있었다.

- 화면 UI를 폰트의 기본 20px 격자로 표시하고 위치·설명 영역 크기를 정수 픽셀에 맞췄다. 하단 효과 두 줄과 호버 설명이 겹치거나 잘리지 않도록 글자 높이에서 배치를 계산한다.
- HintedSmooth와 Bilinear 필터를 사용하고 메뉴판은 60px 글리프를 물리 크기에 맞춰 표시한다. 작은 가격·번호·보유 현황·효과 설명을 확대했다.
- 들고 있는 메뉴판이 안착한 뒤에는 카메라 목표 위치에 맞춰 지연 보간에 의한 미세한 움직임을 줄였다.
- 밝은 테이블 위 호버 설명에는 내용 폭에 맞는 작은 반투명 바탕을 추가했다. 폰트 자체와 기존 픽셀 메시 글자는 유지한다.

## 실제 확인 범위

`Table-hover.png`에서 상단 디버그 안내, 하단 양쪽 효과 문구, 중앙 하단 웨이터벨 설명을 직접 열어 읽었다. `Menu.png`와 `Menu-settled.png`에서 아이템 이름, 무료 가격, 보유 현황, 선택 아이템의 효과, 주문 버튼을 확인했다. 변경 전보다 획이 구분되고 문장을 읽을 수 있는 상태다. 두 시점은 0.35초 간격이며, 메뉴 항목의 화면 위치 변화는 약 0.0070픽셀로 측정됐다.

자동 검사에서는 대표 한글 글리프 존재, 호버 설명, 번들 폰트와 Bilinear 필터, 동일 폰트를 사용하는 월드 글자 32개, E 공용 명령으로 연 실제 무료 메뉴를 확인했다. Q는 필요하지 않았고 W는 껐으며 구매하지 않았다. 검사 전 디버그 플래그를 복원했다. 원래 씬과 Game 뷰 상태로 돌아가 에디터를 열어 두었다. 최종 실행의 컴파일 오류와 실행 예외는 없었다.

이 결과는 실제 Game 뷰의 필요한 세 장면과 자동 상태 검사 범위다. 연속 영상을 시청하거나 모든 해상도·모든 승패 UI 상태를 검사한 것은 아니다. 별도 프리뷰 카메라·RenderTexture·임시 프로젝트는 사용하지 않았다.

처음에는 검증 전용 컴포넌트 연결 오류로 검사가 멈췄다. 컴포넌트 연결과 브리지의 연결 실패 감지·파일 요청 취소 처리를 수정했고, 이후 실제 Play 검사를 완료했다. 이 실패 기록을 성공의 근거로 사용하지 않았다.

# 차례 표시 확인

실행 `turnui-d9d5ddafba9f4167af4c17e475457753`에서 원본 MainScene의 실제 Play 입력 흐름을 사용했다. Game 뷰 541×304에서 `Player-ready.png`, `Boss-turn.png`, `Player-return.png`를 열어 확인했다.

- 플레이어 차례의 중앙 하단에 작은 `내 차례`가 보인다.
- 보스 차례에는 표시가 사라진다.
- 실제 보스 행동이 끝난 뒤 플레이어 차례에서 다시 나타난다.
- 자동 검사에서도 표시의 Repaint 호출, 보스 차례의 미표시, 복귀 시 재표시를 확인했다. 디버그 확정 폭발과 AI 설정은 검사 전 값으로 복원했다. 에디터는 원래 씬으로 돌아가 열린 상태다.

이 기록은 차례 표시 수정의 검증 결과다. 이후 추가한 아이템 호버 들림·중앙 하단 설명·호버 중 차례 문구 숨김은 Play 검증을 요청받지 않아 이 검사 범위에 포함하지 않았다.

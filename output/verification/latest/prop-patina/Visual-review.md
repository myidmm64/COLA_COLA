# PS1 소품 질감 시각 검토

- 요청: 실제 Play 화면을 보며 어색한 질감을 자연스럽게 정리.
- 최종 실행: shake-look-patina-086412feeaed4c5584e0cd32a3ab30f7, 열린 원본 Unity, MainScene, 실제 Game 뷰.
- 수정 전에는 다이얼의 넓은 세로 얼룩, 벨과 버튼의 큰 밝은 반점이 관찰되었다.
- 무늬 크기를 절반으로 줄이고, 강제 8단계 명암과 공통 올리브 밑칠을 제거했다. 종이의 대비를 낮추고 도장색에 가까운 마모만 남겼다.
- 수정 후 Game-view.png와 Item-use-game-view.png를 열어 시각적으로 확인했다. 다이얼의 넓은 줄무늬/벨의 위장무늬 인상이 줄었고, 숫자/라벨은 읽을 수 있으며 원래 재질색이 유지된다.
- 자동 Play 검사: 30개 소품 재질의 128px Point 맵 연결, 캔디 사용, 강도 2 흔들기와 보스 응답, 동작 후 맵 유지 통과. 실행 중 오류/예외 보고 없음.
- E 공용 명령으로만 무료 테스트 아이템을 준비했다. W는 끈 일반 게임 경로, Q는 불필요. E/W 상태 복원. 유료 벨 결제 검사를 대신하지 않는다.
- 시각적 범위: 실제 Game 뷰의 최종 정지 화면과 아이템 사용 중 한 시점. 전체 애니메이션 연속 영상이나 직원 의상 시각 검사는 포함하지 않는다.
- 원래 씬/레이아웃 복원, 에디터 열림 유지. 요청 파일 처리 완료. 최신 PNG 두 장과 보고서만 해당 검사 폴더에 보관.

## 수정과 관찰

- FPS 모델 피벗으로 플레이어 방향을 계산하던 부분을 실제 카메라 방향으로 변경했다. 오른손이 병 오른쪽으로 접근한다.
- 소매가 길게 늘어 화면을 가로지르거나 테이블 안으로 사라지던 배치를 수정했다. 팔꿈치를 테이블 위에서 몸 쪽으로 배치하고 전완 도달 길이를 동작 중 보정한다. 손·손가락 크기와 원본 메시를 유지한다.
- 라벨만 좌우로 돌던 회전축을 바꿨다. 이제 손목 굽힘과 병의 앞뒤 기울기가 함께 바뀐다.
- 플레이어가 병을 조금 더 높이 들도록 해 강도 3의 낮은 자세에서도 테이블과 여유를 확보했다.
- 실제 Game 뷰에서 집기, 접촉, 흔들림의 두 극점, 결과 대기, 내려놓기, 손 복귀의 주요 자세를 열어 확인했다. 보스의 상체 숙이기와 오른손의 병 잡기도 확인했다. 마지막 실행의 접촉·낮은 흔들림·보스 높은 흔들림·복귀 이미지를 다시 확인했다.

화면 관찰은 Play 중 실제 Game 뷰의 필요한 주요 자세를 캡처해 확인한 범위다. 연속 영상 전체를 실시간 시청했다고 주장하지 않는다. 별도 프리뷰 카메라, Camera.Render, RenderTexture는 사용하지 않았다.

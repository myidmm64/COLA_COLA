각 폴더의 Models / Textures / Materials / Prefabs / Docs를 사용하세요.
배치용 에셋은 Prefabs에서 선택해 장면에 끌어 넣으면 됩니다.
라이선스와 원본 안내 문서는 Docs에 보관했습니다.
Unity에서 쓰는 FBX/OBJ를 선택했고, 중복 GLB/DAE와 Blender 원본 및 백업은
Downloads/assets_cola에 그대로 보존했습니다.

콜라 기본형은 GLB를 FBX로 변환해 Pressure BlendShape를 보존했습니다.
Bottle_Shell / Cola_Liquid / Label 세 메시의 Pressure 값을 함께 조절하세요.
Cap_Pivot은 뚜껑 분리 기준점, Burst_Origin은 입구 분출 효과의 기준점입니다.
부푼 형태 파일은 별도 고정형 대체 모델입니다.
